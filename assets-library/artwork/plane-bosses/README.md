# 飞机大战 六款Boss美术

使用内置 imagegen 生成六款透明战机，每款一个独立提示词；未调用外部收费CLI或新增运行库。

1. 苍隼：象牙白/青色双翼巡航长机，双炮与橙色座舱。
2. 疾风：银色/靛紫窄机身与尖掠翼，强调速度。
3. 铜蛇：铜色/象牙白导弹巡洋舰，两侧独立弹舱。
4. 磐石：深蓝钢装甲与大块侧盾，薄荷色核心。
5. 极光：象牙白/紫色航母，带机库和停放护卫。
6. 苍穹：海军蓝/白色旗舰，六组武装与琥珀反应堆。

完整最终提示词见 boss-1-prompt.txt 至 boss-6-prompt.txt；源图为对应 boss-N-source.png，保留在本目录备份，不直接打入PCK。

项目运行时使用 godot/games/plane/assets/boss-N.png，Godot导入限制512像素、有损质量0.86、mipmap。六张导入文件合计约614KiB；每关只加载当前Boss，最大单张含mipmap约1.34MiB。运行时内存仅为贴图估算，未声称整机帧率测量。

prototype-vectors/ 保存已替换的三款几何原型；正式版使用六款精细战机。
