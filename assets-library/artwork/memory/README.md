# 记忆动物图片图集 v1

用于记忆翻牌、记忆对决及其规则图示。使用本次内置 image_gen 生成，不使用第三方图库。原图 animals-source-v1.png 留在本目录，不打入 APK。

最终资源：godot/games/puzzle/assets/animals-atlas.png，1536×768、8列4行、32种动物。Godot 有损导入质量0.86并生成mipmap。两款游戏共用一份延迟加载的纹理；翻牌不解码图片、不创建独立纹理。按用户最新要求，两款记忆游戏最高8×8，32种动物各一对，不使用重复动物角标。

提示词：单张2:1、8×4等距图集，指定猫、金毛犬、兔、熊、熊猫、狐、狮、虎、考拉、浣熊、松鼠、刺猬、水獭、河狸、獾、狼、象、长颈鹿、斑马、河马、犀牛、鹿、羊、马、企鹅、雪鸮、鹦鹉、鸭、鸡、猪、蛙、海龟；统一暖米色底、精致立体自然博物馆风格、自然解剖、柔和光照与细腻毛发/羽毛，适合6—12岁；不是几何矢量、简笔手绘、大眼婴儿风，无文字、无水印，轮廓清楚。

制作使用内置 image_gen，未使用CLI；Godot tests/prepare_memory_art.gd 只负责尺寸处理，原图保持不变。完整英文生成提示词见 generation-prompt.txt。
