# 公共资源约定

- `assets/` 放共用 UI、字体、音效；游戏专用资源放在 `games/<id>/assets/`。
- 使用 `res://` 相对资源路径，避免引用本机绝对路径或运行时联网下载。
- 外部素材需记录文件名、作者、来源链接、许可；未经确认授权的资源不进入发行版。
- 首款正式样板前确定统一配色、字体与按钮状态，再制作成套素材。
- 建议先以 720×1280 逻辑画布设计，兼顾宽高比、安全区、多点触控和上下玩家朝向。
- 图像按实际显示尺寸准备，避免把多张大图常驻内存；场景退出后释放专用资源。

环境验证场景使用基础形状与系统字体；飞机大战的专用矢量美术位于 `games/plane/assets/`，为本项目编写的 SVG。
