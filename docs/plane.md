# 飞机大战（PlaneView）

> 当前正式版本规则见文末 v3.5.1 章节；前面为旧版历史实现。

## 1. 游戏类型与视角

- **类型**：单人射击（纵版卷轴射击）
- **视角**：俯视，玩家飞机在屏幕下方，敌机从上方飞来
- **屏幕方向**：竖屏

## 2. 数据模型

```kotlin
data class Bullet(var x: Float, var y: Float, val enemy: Boolean)
// enemy = true 为敌方子弹，false 为玩家子弹

data class Enemy(var x: Float, var y: Float, val speed: Float)
// speed 为该敌机的下落速度（每架随机）

val bullets = ArrayList<Bullet>    // 场上所有子弹
val enemies = ArrayList<Enemy>     // 场上所有敌机
var planeX, planeY: Float         // 玩家飞机位置
var planeR: Float                  // 玩家碰撞半径 = dp(22)
var fireTimer: Float               // 自动射击计时器
var spawnTimer: Float              // 敌机生成计时器
var score: Int                     // 当前得分
var lives: Int                     // 剩余生命（初始 3）
var over: Boolean                  // 游戏结束标志
```

## 3. 初始化逻辑（reset）

```kotlin
bullets.clear()
enemies.clear()
fireTimer = 0f              // 立即发射第一颗子弹
spawnTimer = 1.2f           // 首架敌机延迟 1.2 秒
score = 0
lives = 3
over = false
setScore(0)
start()
```

`onLayout` 中设置：`planeR = dp(22)`，`planeX = w/2`，`planeY = h * 0.8`。

## 4. 输入处理

- **滑动 / 按下**：`planeX = event.x`（钳制 `[planeR, width - planeR]`），`planeY = event.y`（钳制 `[height*0.4, height - planeR]`）。
- 玩家飞机可拖动到屏幕上半部分以下的任意位置。
- **自动射击**：无需手动开火，由 `update()` 中的定时器控制。

## 5. 核心更新循环（update(dt)）

每帧执行：

1. **自动射击**：`fireTimer -= dt`，归零时在玩家飞机正上方生成一颗子弹，重置间隔 `0.28f` 秒。
2. **敌机生成**：`spawnTimer -= dt`，归零时在屏幕顶部随机位置生成敌机：
   - 间隔：`(1.2 - score * 0.004).coerceAtLeast(0.4)` 秒，随分数增加而缩短
   - 位置：屏宽 10%~90% 随机
   - 速度：`height * (0.35 + random * 0.3)`，每架不同
3. **子弹移动**：
   - 玩家子弹：`y -= height * 0.9 * dt`（向上飞）
   - 敌方子弹：`y += height * 0.7 * dt`（向下飞）—— **注意：当前源码中未生成敌方子弹**（`enemy` 字段存在但无使用路径）
   - 出屏幕（`y < -20` 或 `y > height + 20`）移除
4. **敌机移动**：`y += speed * dt`
   - 飞出屏幕底部（`y > height + dp(30)`）：移除敌机，扣一条命；命归零 → 结束
5. **子弹-敌机碰撞**：遍历玩家子弹，与所有敌机做距离检测（`hypot < dp(30)`）：
   - 命中：移除敌机，子弹标记 `y = -999`（下帧移除），加 10 分
6. **敌机-玩家碰撞**：遍历敌机，与玩家飞机做距离检测（`hypot < planeR + dp(24)`）：
   - 碰撞：立即结束游戏，`"被敌机撞毁！"`

## 6. 胜负判定

- **失败条件**（任一触发）：
  1. 敌机飞出屏幕底部（`lives--`，归零结束），消息 `"敌机突破防线！得分 {score}"`
  2. 敌机直接撞上玩家飞机，消息 `"被敌机撞毁！得分 {score}"`
- **无胜利条件**：纯生存模式，尽可能得高分。

## 7. 边界与特殊规则

- **敌方子弹未实现**：`Bullet` 有 `enemy` 字段，`update` 中有敌方子弹的移动逻辑，但没有任何代码生成 `enemy = true` 的子弹。这是一个预留接口。
- **碰撞半径差异**：玩家碰撞半径 `planeR = dp(22)`，敌机视觉半径 `dp(24)`，碰撞检测用 `planeR + dp(24)`。
- **子弹命中后延迟移除**：命中敌机后设 `b.y = -999` 而非直接移除（因为在外层遍历 `bullets` 时不能安全删除），下帧由边界检查移除。
- **飞机可移动范围**：Y 轴限制在 `[height*0.4, height - planeR]`，不能飞到屏幕最上方。
- **生成速率随分数递增**：`spawnTimer = max(0.4, 1.2 - score * 0.004)`，得分越高敌机越密集。

## 8. 渲染要求

- 玩家飞机：蓝色三角形（`0xFF4A6CF7`），用 `Path` 绘制。
- 敌机：红色实心圆（`0xFFFF5252`），半径 `dp(24)`。
- 子弹：黄色小圆（`0xFFF5D547`），半径 `dp(5)`。
- 顶部 HUD：得分（白色）、生命（❤ 红色符号）。
- 底部提示：`"拖动飞机自动开火 · 击落敌机"`。

## 9. v3.0.0-dev Godot 迁移

正式入口为 `res://games/plane/plane.tscn`，标题「星航防线」；旧 `PlaneView` 保留为历史实现。游戏数量和 `plane` 成绩键不变。

规则以本文前述玩法为基线：三格防线、漏过扣一格、直接相撞结束、击落 +10 分，无敌方子弹。Godot 使用逻辑坐标：碰撞半径为 22/24，玩家子弹命中距离为 30；单帧 dt 钳制到 0..0.05 秒。子弹改为扫掠检测并立即移除，一颗仅命中沿途第一架敌机。玩家初始位置为画布 (0.5w, 0.8h)，重开必定复位；手指上方 55 单位是输入偏移，底部保留 90 单位安全区。

Godot 画面使用矢量战机纹理、层次星空、星球背景、尾焰与命中碎屑。暂停和结算由公共 GameShell 处理，后台不自动继续；成绩通过主进程服务保存，最近 128 个回执内防止重复写入。

## 10. v3.5.1 六关战役（初版规则，数值以v3.6.1为准）

当前Godot实现新增六关战役、独立叠加的弹道/射速/弹种技能、可击落且不追踪的敌方导弹、六款独立精细战机与带预警的分阶段Boss。5点耐久，撞击与中弹扣1点，短暂无敌且不掉武器；漏过普通敌机不扣耐久。技能补给8秒未接到会送达，击破Boss修复1点，第六关Boss击破通关。

完整流程、数值、敌人和性能上限见 [飞机大战战役设计](development/飞机大战战役设计.md)。旧版“三格防线、漏机扣命、相撞立即结束、无敌方弹药”已不适用于正式Godot入口。


## 11. v3.6.1 当前规则

主炮保持普通弹，弹道/快射只强化主炮；单枚导弹独立冷却：直射0.85秒/2伤害，追踪1.1秒/1.6伤害。追踪无溅射。补给必须实际接住，12秒漏接消失，溢出不发放，重复满级装备不送护盾。第二关起Boss每轮增加瞄准普通弹，后几关射击更紧凑、敌弹更快，第四关起小飞机也能射击；预警仍为0.9秒，敌方导弹仍不追踪且可拦截。
