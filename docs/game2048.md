# 2048（game2048）

## 1. 游戏类型与视角

| 项目 | 值 |
|------|---|
| 类型 | 单人 |
| 视角约定 | 无方向 |
| 屏幕方向 | 竖屏（自适应） |

## 2. 数据模型

```kotlin
val size: Int = 4                    // 4×4 棋盘
val board = IntArray(size * size)    // 0=空，其他为数字值
var score: Int = 0
var won: Boolean = false             // 已合成 2048
var over: Boolean = false            // 游戏结束
```

## 3. 初始化逻辑

- 全部清零，`score=0`，`won=false`，`over=false`
- 随机在空位生成 2 个方块（90% 为 2，10% 为 4）

## 4. 输入处理

- 使用 `SwipeHelper` 识别四方向滑动（上下左右）
- 滑动触发 `move(dx, dy)`

## 5. 核心更新循环

`update(dt)` 为空——2048 是纯事件驱动，无帧循环。

```
move(dx, dy):
  若 over 或 paused → return
  对每一行/列（按滑动方向决定遍历顺序）：
    提取该行数字序列，过滤空格
    slideLine：相邻相同则合并（前一个翻倍），合并值加入 gained
    写回棋盘
  若无任何移动 → return
  score += gained; setScore(score)
  若未 won 且棋盘含 2048 → won=true
  spawn()：随机空位生成 2 或 4
  若 noMoves() → over=true; gameOver()
```

## 6. 胜负判定

- **胜利**：棋盘出现 2048（设 `won=true`，但不结束，可继续刷高分）
- **失败**：无空位且无相邻相同方块可合并 → `gameOver(score, won, ...)`

## 7. 边界与特殊规则

1. **合并规则**：同一次滑动中，每个位置最多合并一次（从滑动方向开始顺序处理）
2. **slideLine 实现**：过滤空格 → 从头遍历，相邻相同则合并并跳过下一个 → 补零到满
3. **得分**：每次合并加入合并后的值（如两个 64 合并得 128 分）
4. **新块概率**：90% 出 2，10% 出 4
5. **胜负判定顺序**：先判定胜利（出现 2048），再判定失败（无路可走）
6. **胜利后继续**：`won=true` 后不结束，显示提示"已合成 2048，继续刷高分！"

## 8. 渲染要求

- 4×4 方格，每格有独立颜色（根据数值变化）
- 数字 ≤4 用深色文字，>4 用白色文字
- 数字 <100 字号较大，≥100 字号较小
- 已合成 2048 时顶部显示金色提示
