## 2. Kotlin 语言速成

> 对比 C++ 和 Java，只讲本项目实际用到的语法。

### 2.1 变量声明

```kotlin
// C++: int x = 5;  Java: int x = 5;
val x = 5           // val = 不可变（final），编译器自动推断类型为 Int
var y = 10           // var = 可变

// 显式类型
val name: String = "snake"   // 等价于 Java 的 final String name = "snake";
val score: Int = 0           // Kotlin 用 Int（首字母大写），不是 int
```

**关键区别**：Kotlin 的 `val` 相当于 Java 的 `final`，`var` 相当于普通变量。
本项目中 90% 的变量用 `val`——不可变是 Kotlin 的默认偏好。

### 2.2 函数定义

```kotlin
// C++: int add(int a, int b) { return a + b; }
// Java: int add(int a, int b) { return a + b; }
fun add(a: Int, b: Int): Int = a + b    // 单表达式函数，= 直接返回

// 多行函数
fun greet(name: String): String {
    val msg = "Hello, $name"    // 字符串模板：$变量名 或 ${表达式}
    return msg
}

// 无返回值（Unit 相当于 Java 的 void，可省略）
fun doSomething(): Unit { ... }
fun doSomething() { ... }       // 等价
```

### 2.3 类与继承

```kotlin
// Java: public class SnakeGameView extends GameView { ... }
// Kotlin: 用冒号代替 extends，open 关键字表示可继承
class SnakeGameView(context: Context) : GameView(context) {
    // 构造器参数直接写在类名后面，自动成为属性
    // context: Context 相当于 Java 的构造器参数
}

// 抽象类（不能直接实例化，类似 C++ 纯虚基类）
abstract class GameView(context: Context) : View(context) {
    abstract fun update(dt: Float)      // 抽象方法（子类必须实现）
    protected open fun onLayout(w: Int, h: Int) {}  // open = 可被子类重写
}
```

**对比**：`abstract` = C++ 的纯虚函数，`open` = C++/Java 的普通虚函数，
Kotlin 默认所有类和方法都是 final 的（不可继承/重写），必须用 `open` 显式允许。

### 2.4 数据类（data class）

```kotlin
// C++: struct Pt { int x, y; bool operator==(const Pt&) const; ... };
// Java: 需要手写 equals/hashCode/toString/getter/setter（Lombok 自动生成）
data class Pt(val x: Int, val y: Int)
// 自动生成：equals()、hashCode()、toString()、copy()、componentN()

val p = Pt(3, 5)
println(p)           // Pt(x=3, y=5)  ← 自动生成的 toString
val p2 = p.copy(x = 7)  // Pt(x=7, y=5)  ← 复制并修改部分字段
```

本项目中的 data class：`GameSpec`、`GameResult`、`Pt`、`Btn`。

### 2.5 对象声明（object）

```kotlin
// Java: public class Ui { public static void styleDialog(...) { ... } }
// Kotlin 的 object 是单例——全局只有一份实例，方法相当于 static
object Ui {
    fun rounded(color: Int, radiusDp: Float, density: Float): GradientDrawable { ... }
    fun styleDialog(dialog: AlertDialog, density: Float) { ... }
}
// 调用：Ui.rounded(...)  不需要 Ui.INSTANCE.rounded(...)
```

本项目中的 object：`Ui`、`GameRegistry`、`SoundManager.Companion`。

### 2.6 lambda 表达式（闭包/函数指针）

```kotlin
// C++: auto callback = [](int x) { printf("%d", x); };
// Java: Consumer<Integer> callback = x -> System.out.println(x);
// Kotlin: 更简洁，最后一个参数是 lambda 时可以提到括号外面

// 类型：(参数类型) -> 返回类型
val onSwipe: (dx: Int, dy: Int) -> Unit = { dx, dy -> println("$dx, $dy") }

// 最常见的用法：点击监听器
button.setOnClickListener { doSomething() }  // 单参数 lambda 可用 it

// SwipeHelper 的构造器接收一个函数参数
class SwipeHelper(context: Context, private val onSwipe: (dx: Int, dy: Int) -> Unit)
```

本项目大量使用 lambda：所有按钮的 `setOnClickListener`、`SwipeHelper` 的回调、
`DualConsentView` 的 `onBothReady`/`onExit` 回调。

### 2.7 作用域函数（apply/let/run/with）

```kotlin
// apply：对象初始化器，返回对象本身
// C++ 没有对应物，Java 需要 Builder 模式
val paint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
    color = 0xFF4A6CF7.toInt()    // this 是 Paint 实例
    textAlign = Paint.Align.CENTER
    textSize = 48f
}
// 等价于 Java:
// Paint paint = new Paint(Paint.ANTI_ALIAS_FLAG);
// paint.setColor(0xFF4A6CF7);
// paint.setTextAlign(Paint.Align.CENTER);
// paint.setTextSize(48f);

// with：对已有对象执行多个操作
with(canvas) {
    drawRect(rect, paint)
    drawCircle(cx, cy, r, paint)
}
```

本项目中最常用的是 `apply`——几乎所有 Paint/View 的初始化都用它。

### 2.8 安全调用与空安全

```kotlin
// Kotlin 的类型系统区分可空和非空：
val name: String = "hello"    // 非空，赋 null 编译报错
val name: String? = null       // 可空（加 ? 后缀）

// 安全调用：?. 相当于 Java 的 if (obj != null) obj.method()
sound?.play(rawId)    // sound 为 null 时整个表达式不执行，不会 NullPointerException

// Elvis 操作符：?: 提供默认值
val len = name?.length ?: 0   // name 为 null 时返回 0

// 非空断言：!! 强制解包（危险，null 时抛异常，尽量避免）
val len = name!!.length
```

本项目中 `callbacks`、`sound`、`haptic`、`voice` 都是可空类型（`?`），
因为它们在 GameView 构造时还未注入，使用时用 `?.` 安全调用。

### 2.9 字符串模板

```kotlin
// C++: "score: " + std::to_string(score)
// Java: "score: " + score   （自动转字符串，但复杂表达式需要 + 拼接）
// Kotlin: $变量 或 ${表达式}
val msg = "蛇身长度 ${body.size}"        // ${} 包裹表达式
val text = "得分 $score"                  // $ 直接引用变量
val hex = "颜色: 0x${Integer.toHexString(color)}"  // 嵌入方法调用
```

### 2.10 集合操作

```kotlin
// Kotlin 集合是 Java 集合的增强封装，支持链式函数式操作
val free = (0 until cols).flatMap { x ->      // flatMap = 展平嵌套列表
    (0 until rows).map { y -> Pt(x, y) }      // map = 转换每个元素
}.filter { it !in occupied }                    // filter = 过滤

food = free.random()                           // random = 随机选一个

// take/drop = 取前N个/跳过前N个
hist.take(10).forEachIndexed { i, s -> ... }

// joinToString = 连接为字符串
hist.take(MAX_HISTORY).joinToString(",")  // "100,80,60"

// none/all/any = 判断条件
if (board.none { it == EMPTY }) { /* 棋盘满了 */ }
if (body.any { it == nh }) { /* 咬到自己 */ }
```

### 2.11 when 表达式（增强版 switch）

```kotlin
// C++: switch/case; Java: switch/case（有限制）
// Kotlin: when 可以匹配值、范围、类型，且是表达式（有返回值）
val points = when (cleared.coerceAtMost(4)) {
    1 -> 100
    2 -> 300
    3 -> 500
    4 -> 800
    else -> 0
}

// 匹配条件
when {
    spec.aiClass != null -> showModeDialog(root)
    spec.category == GameCategory.DUEL -> showDualConsent(root)
    else -> showRulesDialog(root)
}
```

### 2.12 属性访问器（getter/setter 语法糖）

```kotlin
// Java: private boolean soundEnabled;
//       public boolean isSoundEnabled() { return prefs.getBoolean("sound", true); }
//       public void setSoundEnabled(boolean v) { prefs.edit().putBoolean("sound", v).apply(); }
// Kotlin: 用 var + get()/set() 定义属性，外部像普通字段一样访问
var soundEnabled: Boolean
    get() = prefs.getBoolean("sound", true)   // 读取时调用
    set(v) { prefs.edit().putBoolean("sound", v).apply() }  // 写入时调用

// 调用方：
settings.soundEnabled = true    // 实际调用 set(true)
if (settings.soundEnabled) ...  // 实际调用 get()
```

## 3. Gradle 构建系统

> 相当于 C++ 的 CMake/Makefile，Java 的 Maven pom.xml。

### 3.1 两个构建文件

**`build.gradle.kts`（根目录）** — 声明插件版本：

```kotlin
plugins {
    id("com.android.application") version "8.13.2" apply false  // Android 构建插件
    id("org.jetbrains.kotlin.android") version "2.1.21" apply false  // Kotlin 支持
}
```

**`app/build.gradle.kts`（应用模块）** — 配置应用参数：

```kotlin
plugins {
    id("com.android.application")     // 应用 Android 插件
    id("org.jetbrains.kotlin.android") // 应用 Kotlin 插件
}

android {
    namespace = "com.minigames.collection"   // 应用包名（Java 包的根路径）
    compileSdk = 36                           // 编译时使用的 Android SDK 版本
    defaultConfig {
        applicationId = "com.minigames.collection"  // 应用唯一标识（发布到商店用）
        minSdk = 33                                 // 最低支持 Android 版本（Android 13）
        targetSdk = 36                              // 目标 Android 版本
        versionCode = 12                            // 内部版本号（每次发布递增）
        versionName = "2.2.0"                       // 用户可见版本号
    }
}

dependencies {
    implementation("org.jetbrains.kotlin:kotlin-stdlib:2.1.21")  // Kotlin 标准库
    // 没有其他依赖！整个 app 零第三方库。
}
```

### 3.2 关键概念

| Gradle 概念 | 对应 C++/Java | 说明 |
|---|---|---|
| plugin | 编译工具链 | AGP = Android 构建工具，Kotlin = Kotlin 编译器 |
| compileSdk | 编译目标 | 使用哪个版本的 Android API 来编译 |
| minSdk | 最低运行版本 | 低于此版本的设备无法安装 |
| targetSdk | 行为目标 | 告诉系统"我针对哪个版本优化" |
| implementation | 链接库 | 相当于 C++ 的 `-l` 或 Java Maven 的 `<dependency>` |
| apply false | 仅声明不启用 | 根脚本只声明版本，子模块再 apply |

### 3.3 settings.gradle.kts

```kotlin
pluginManagement { repositories { google(); mavenCentral() } }  // 插件从哪下载

rootProject.name = "MiniGames"   // 项目名称
```

## 4. Android 核心概念

### 4.1 Activity（页面/窗口）

Activity 是 Android 的"页面"容器，相当于：
- C++ 的窗口类（Win32 的 HWND + WndProc）
- Java Swing 的 JFrame
- Web 的单页面应用的一个页面

```
Activity 生命周期（系统自动管理）：

onCreate()  → 页面创建（初始化 UI、数据）
onStart()   → 页面即将可见
onResume()  → 页面获得焦点（用户可交互）
onPause()   → 页面失去焦点（如弹出对话框、切到后台）
onStop()    → 页面不可见
onDestroy() → 页面销毁（释放资源）
```

本项目只有 3 个 Activity：

| Activity | 作用 | 对应文件 |
|---|---|---|
| `MainActivity` | 主菜单 | `MainActivity.kt` |
| `GameActivity` | 游戏容器 | `GameActivity.kt` |
| `SettingsActivity` | 设置页 | `SettingsActivity.kt` |

**本项目直接继承 `Activity`（最基础的），没有使用 `AppCompatActivity` 或 Jetpack。**

### 4.2 View（视图/控件）

View 是 Android 所有可视元素的基类，相当于：
- C++ 的自定义绘图控件
- Java Swing 的 JComponent
- HTML 的 DOM 元素

```
View 层级树（本项目的 GameActivity 结构）：

FrameLayout (root，根容器)
├── GameView (游戏画面，index=0，最底层)
│   └── 所有游戏内容通过 Canvas 绘制
└── FrameLayout (overlay，悬浮控制层，index=1，最上层)
    ├── LinearLayout (左上角：退出 + 设置按钮)
    ├── LinearLayout (右上角：暂停 + 重开 + 帮助按钮)
    └── TextView (右下角：得分胶囊)
```

**FrameLayout**：子 View 堆叠显示（后添加的在上层），类似 CSS 的 `position: absolute`。
**LinearLayout**：子 View 线性排列（水平或垂直），类似 CSS 的 `flex`。

### 4.3 Intent（页面间通信）

Intent 是 Activity 间传参的机制，相当于函数调用时传参数：

```kotlin
// MainActivity → GameActivity（传递游戏 id）
startActivity(
    Intent(this, GameActivity::class.java)  // 目标 Activity
        .putExtra("game", spec.id)           // 附带参数（key-value）
)

// GameActivity 中读取参数
val gameId = intent.getStringExtra("game")  // 按 key 读取字符串
```

### 4.4 AndroidManifest.xml

应用清单文件，声明所有 Activity、权限、应用元数据：

```xml
<manifest>
    <application android:label="迷你游戏合集">
        <!-- 主 Activity（启动入口） -->
        <activity android:name=".MainActivity">
            <intent-filter>
                <action android:name="android.intent.action.MAIN"/>
                <category android:name="android.intent.category.LAUNCHER"/>
            </intent-filter>
        </activity>
        <activity android:name=".GameActivity"/>
        <activity android:name=".SettingsActivity"/>
    </application>
</manifest>
```

### 4.5 dp 和 sp（密度无关单位）

| 单位 | 用途 | 说明 |
|---|---|---|
| px | 像素 | 实际屏幕像素，不同设备差异大 |
| dp | 布局尺寸 | 密度无关像素，1dp 在 mdpi=1px，在 xhdpi=2px |
| sp | 字号 | 类似 dp 但联动系统字体大小设置 |

转换代码（本项目写在 GameView 基类中）：

```kotlin
fun dp(v: Int): Int = (v * resources.displayMetrics.density).toInt()
fun sp(v: Float): Float = v * resources.displayMetrics.scaledDensity
```

## 5. Android View 与 Canvas 绘图

> 本项目所有游戏画面都用 Canvas 2D API 手绘，相当于 C++ 的 GDI 或 HTML Canvas。

### 5.1 自定义 View 的核心方法

```kotlin
class MyGameView(context: Context) : View(context) {

    // 1. 尺寸确定后调用（计算布局参数）
    override fun onSizeChanged(w: Int, h: Int, oldw: Int, oldh: Int) { ... }

    // 2. 绘制（每帧或 invalidate() 后调用）
    override fun onDraw(canvas: Canvas) {
        // canvas 就是"画布"，所有绘制操作都在上面进行
    }

```

### 5.2 Canvas 常用绘制方法

```kotlin
// 坐标系：左上角 (0,0)，x 向右，y 向下

// 矩形
canvas.drawRect(left, top, right, bottom, paint)
canvas.drawRect(RectF(l, t, r, b), paint)

// 圆角矩形
canvas.drawRoundRect(rect, radiusX, radiusY, paint)

// 圆
canvas.drawCircle(cx, cy, radius, paint)

// 线
canvas.drawLine(startX, startY, endX, endY, paint)

// 文字
canvas.drawText("Hello", x, y, paint)  // y 是 baseline（文字底部基线）

// 位图
canvas.drawBitmap(bitmap, left, top, paint)
```

### 5.3 Paint（画笔）

Paint 控制绘制的样式——颜色、粗细、字体等：

```kotlin
val paint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
    color = 0xFF4A6CF7.toInt()     // ARGB 颜色（0xAARRGGBB）
    style = Paint.Style.FILL       // 填充模式（FILL/STROKE/FILL_AND_STROKE）
    strokeWidth = 2f               // 线宽（STROKE 模式时）
    textAlign = Paint.Align.CENTER // 文字对齐（LEFT/CENTER/RIGHT）
    textSize = 48f                 // 字号（像素）
    typeface = Typeface.DEFAULT_BOLD  // 字体（粗体）
    setShadowLayer(radius, dx, dy, color)  // 阴影
}
```

### 5.4 RectF（矩形区域）

```kotlin
val rect = RectF(left, top, right, bottom)  // 浮点矩形
val rect = Rect(left, top, right, bottom)    // 整数矩形

// 常用方法
rect.contains(x, y)     // 判断点是否在矩形内（碰撞检测/点击判定）
rect.centerX()           // 中心 x
rect.centerY()           // 中心 y
rect.set(l, t, r, b)    // 重新设置
```

### 5.5 本项目的绘制模式

```
GameView 基类（Choreographer 帧循环）：
  每帧 doFrame() → update(dt) → invalidate()
                                   ↓
                              onDraw(canvas)
                                   ↓
                              drawGame(canvas)   ← 子类实现
```

所有 Paint 对象在类初始化时创建（避免每帧 new 对象导致 GC 抖动），
`drawGame()` 中只做绘制操作，不创建新对象。

```kotlin
        // vx/vy 是速度（像素/秒），正值向右/向下
        if (Math.abs(vx) > Math.abs(vy)) {
            // 水平滑动为主
        } else {
            // 垂直滑动为主
        }
```

## 9. 多线程基础

### 9.1 Android 的线程规则

**核心规则：UI 操作必须在主线程（UI 线程）执行。**

耗时操作（网络、大量计算）在后台线程执行，完成后用 `post{}` 回到主线程更新 UI。

```kotlin
// 后台线程执行耗时计算
Thread {
    val result = doHeavyComputation()   // 在后台线程
    post {                               // 回到主线程
        updateUI(result)                 // 安全更新 UI
    }
}.start()
```

本项目中 `GomokuAiView` 的 AI 计算使用此模式。

### 9.2 更高级的方案（本项目未使用，了解即可）

| 方案 | 说明 |
|---|---|
| Handler/Looper | Android 原生消息队列机制 |
| Coroutines | Kotlin 的协程（轻量级线程，推荐现代 Android 开发使用） |
| AsyncTask | 已废弃，不要使用 |

### 步骤 1：创建游戏 View 类

```kotlin
class YourGameView(context: Context) : GameView(context) {

        reset()
    }

    // 4. 帧更新（游戏逻辑）
    override fun update(dt: Float) {
        // 移动、碰撞检测、状态更新
    }

    // 5. 绘制画面
    override fun drawGame(canvas: Canvas) {
        canvas.drawRect(gameRect, bgPaint)
        // 绘制所有游戏元素
    }

    // 6. 触摸处理
    override fun onTouch(event: MotionEvent) {
        if (event.action == MotionEvent.ACTION_DOWN) {
            // 处理点击
        }
    }

        score = 0
        setScore(0)
        start()  // 必须调用！
```

### 12.3 常见问题

| 问题 | 原因 | 解决 |
|---|---|---|
| `ClassCastException` | 反射创建的类不是 GameView 子类 | 检查 className 是否拼写正确 |
| `ClassNotFoundException` | className 拼写错误或类不存在 | 检查 GameSpec 中的 className |
| UI 卡顿 | 在主线程执行了耗时操作 | 用 Thread + post{} 模式 |
| 音效不响 | 设置页关闭了音效 | 检查 SettingsStore.soundEnabled |
| 画面不更新 | 忘记调用 start() 或 invalidate() | reset() 末尾必须调用 start() |

### 12.2 代码热重载

修改代码后需要重新构建安装（`./gradlew installDebug`），不像 Web 有热重载。
但 Android Studio 的 Apply Changes 功能可以部分实现增量部署。
