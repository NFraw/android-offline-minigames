# 斗兽棋（AnimalView）

## 1. 游戏类型与视角

- **类型**：双人棋类（斗兽棋 / Jungle Chess）
- **视角**：俯视，9×7 棋盘。红方（正数）在底部，黑方（负数）在顶部。棋子文字通过 `drawPieceText` 处理对向视角——黑方棋子文字旋转 180° 正对上方玩家。
- **屏幕方向**：竖屏

## 2. 数据模型

```kotlin
companion object {
    const val N = 9           // 棋盘列数
    const val M = 7           // 棋盘行数
    const val RANK = 8        // 棋子种类数
    // 棋子编码：1..8（象1 狮2 虎3 豹4 狼5 狗6 猫7 鼠8）
    // 红方用正值，黑方用负值，0 为空
    const val ELEPHANT = 1
    const val LION = 2
    const val TIGER = 3
    const val LEOPARD = 4
    const val WOLF = 5
    const val DOG = 6
    const val CAT = 7
    const val RAT = 8
    val NAMES = arrayOf("", "象", "狮", "虎", "豹", "狼", "狗", "猫", "鼠")
    // 战斗等级映射：棋子编码 → 等级（8 最高，1 最低）
    // 象=8, 狮=7, 虎=6, 豹=5, 狼=4, 狗=3, 猫=2, 鼠=1
    val RANK_OF = intArrayOf(0, 8, 7, 6, 5, 4, 3, 2, 1)
}

val board = IntArray(N * M)   // 棋盘，行优先存储，idx = r * N + c
var selected: Int              // 当前选中的棋子索引，-1 表示未选中
var turn: Int                  // 当前回合：0=红方（下），1=黑方（上）
var over: Boolean              // 游戏是否已结束

// 布局相关（由 onLayout 计算）
var cell: Float                // 单元格边长（像素）
var boardLeft: Float           // 棋盘左上角 X
var boardTop: Float            // 棋盘左上角 Y
```

## 3. 初始化逻辑（reset）

1. 清空 `board` 全部为 0。
2. 按官方标准布局放置棋子（兽穴 `(4,0)` 和 `(4,6)` 留空）：
   - **黑方（负数，第 0 行）**：左半 `狮 象 鼠 猫`，右半 `狼 狗 豹 虎`（索引 0-3 和 5-8）
   - **红方（正数，第 6 行）**：左半 `虎 豹 狗 狼`，右半 `猫 鼠 象 狮`（索引 0-3 和 5-8）
3. `selected = -1`，`turn = 0`（红方先手），`over = false`。
4. 调用 `start()`。

## 4. 输入处理

- **触发条件**：`ACTION_DOWN`，且 `!over && !paused`
- **坐标转换**：触摸坐标 → 列 `c`、行 `r`，越界检查 `inBounds(c, r)`
- **未选中时**（`selected < 0`）：点击己方棋子则选中，播放 CLICK 音效
- **已选中时**：
  - 点击同一棋子：取消选中
  - 点击己方另一棋子：改选该棋子
  - 点击空格或敌方棋子：调用 `canMoveTo` 和 `canCapture` 判定合法性
    - 合法：执行移动（吃子播放 EAT 音效，空移播放 MOVE 音效），检查胜负
    - 不合法：取消选中

## 5. 核心更新循环（update(dt)）

**空实现** —— 纯回合制棋类，所有状态变更在 `onTouch` 中即时完成。

## 6. 胜负判定

移动完成后立即检查，按以下顺序：

1. **进入对方兽穴获胜**：
   - 红方棋子进入黑方兽穴（`idx == 4`，即 `(4,0)`）→ 红方胜
   - 黑方棋子进入红方兽穴（`idx == (M-1)*N+4`，即 `(4,6)`）→ 黑方胜
   - 注意：己方兽穴在 `canMoveTo` 中已被拦截，不可能走入自己巢穴
2. **吃光对方获胜**：对方无剩余棋子（`board.count { it != 0 && side(it) == 1-turn } == 0`）
3. **换手**：以上均不满足则 `turn = 1 - turn`

## 7. 边界与特殊规则

- **棋子战斗等级**：`RANK_OF` 映射将棋子编码转为等级（象=8 最高，鼠=1 最低）。`rankOf(p)` 取绝对值后查表。
- **鼠吃象**：等级 1（鼠）可吃等级 8（象），`canCapture` 中特判 `pr==1 && tr==8` 返回 true。
- **象不能吃鼠**：`pr==8 && tr==1` 返回 false。
- **同级互吃**：等级相同返回 false（`pr > tr`），不能互吃。
- **水域**：坐标 `(3..5, 1..2)` 和 `(3..5, 4..5)` 共 12 格为水面。
  - 只有鼠（等级 1）可进入/离开水面。
  - 岸上棋子不能吃水中的鼠（`tWater && !pWater` 返回 false）。
  - 水中鼠不能吃岸上棋子（`pWater && !tWater` 返回 false）。
  - 水中鼠对水中鼠：可互吃（`pWater` 时直接返回 true）。
- **狮虎跳河**：等级 6（狮）和 7（虎）可跳过河流：
  - 横向跳 4 格（跨 3 格水）：检查中间 3 格全是水面且无子
  - 纵向跳 3 格（跨 2 格水）：检查中间 2 格全是水面且无子
- **陷阱**：围绕兽穴的 3 格（黑方：`(3,0)`, `(5,0)`, `(4,1)`；红方：`(3,6)`, `(5,6)`, `(4,5)`）。
  - 目标在**攻击方所属**陷阱内：被削弱，任意棋子可吃（含鼠吃象）
  - 目标在**自己所属**陷阱内：不享受保护，按正常等级/水域规则比较
  - 兽穴正前方的陷阱格（黑 `(4,1)`、红 `(4,5)`）是陆地：本作棋盘压缩为 9×7，河面横带 `y∈{1,2}∪{4,5}` 原本会覆盖这两格，导致它们被渲染成水格且除鼠外无法进入，陷阱形同虚设
- **兽穴**：任何棋子都不能进入己方兽穴（`canMoveTo` 中拦截）。

## 8. 渲染要求

- 棋盘占屏幕的 98%，居中。每格为圆角矩形（`dp(4)` 圆角）。
- 水域用蓝色 `waterPaint`（`0xFF37C2F0`），陷阱用棕色 `trapPaint`（`0xFFB25B33`）+ 描边，普通格用米色 `cellPaint`（`0xFFD9B38C`）。
- 棋子：圆形（半径 `cell * 0.36`），红方 `0xFFE8503A`，黑方 `0xFF1C2333`。文字白色，大小 `cell * 0.5`。
- 选中高亮：黄色描边 `selPaint`（`0xFFF5D547`，4px 宽）。
- 陷阱无棋子时显示半透明"陷"字，兽穴显示"穴"字。
- 底部显示当前回合方和规则提示。
