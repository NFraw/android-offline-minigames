## 当前边界与环境说明

- 实测渲染设备是 API 36.1 模拟器 + NVIDIA 宿主 GPU，尚未做实体安卓手机性能或续航验收。
- 现有 AVD 默认的旧 SwiftShader 软件后端在当前 Godot 着色器上超出 uniform 上限，画面空白；启动脚本已显式选择 `-gpu host`。
- 上游运行时启动仍记录 `xr/shaders/enabled` 属性警告，以及部分启动的着色器缓存重编译警告；宿主 GPU 上未出现着色器链接错误或 AndroidRuntime 崩溃，渲染与操作测试均通过。
- aapt 不支持本机中文 APK 路径，权限检查使用临时英文路径副本；临时文件已清理。
- APK 包含全部上游 CPU 架构，原生库压缩；后续可按设备或发行渠道进一步裁剪，尚未进行自定义引擎裁剪。
- 当前工程只有开发验证场景；正式游戏迁移、精品素材、跨进程成绩/设置/存档协议留待正式游戏开发阶段完成。
- 原仓库保留；本次代码、工具和文档变更均在新版目录。
