# v3.3.0-kids 适龄改造

按小学1—6年级用户调整，目标是清楚、好操作、有游戏自己的氛围。以轻量矢量绘制为主，不增加大型美术依赖。

- 29款专属主题、三页短句图示与能力小目标：记忆、空间、计算、预测、计划及耐心等待。大厅玩法和游戏内规则均可翻页。
- 入场简化：直接开始/准备；人机两选项，算术三档；双人准备窗先展示关键规则。冰壶全员同向准备。
- 经典Windows灰色扫雷：立体格、数字配色、旗与雷、计时和笑脸。
- 动物记忆为默认；数字/颜色可选，单人4×4、6×6、8×8。双人4×4、6×6、8×8三关累计。
- 井字棋移到中间，去掉最后一手的中心小点；棋盘布局尽量居中。
- 双蛇按键改为有层次的大箭头，交错底色和加粗网格；算术题目、输入、数字键放大。
- 乒乓球场加长并增加球场标线；地鼠有缓入缓出探头、胡须和命中反馈；琴房与街机方块各有自己的场地。
- 修正规则：白块误点立即失败、漏黑块失败；暗棋炮隔一子远吃明子；象棋悔棋确认朝向对手。
- 西蒙先留观察时间再闪灯；延长亮灯并增加高对比描边，首盏不再转瞬即逝。
- 冰壶支点限于底部框、拉动限长、短预览线，拉得越远力度越大；壶使用棕金、紫、松绿、石灰蓝并加浅色边框。

本次只做简短基础检查与场景加载检查，不追加完整对局测试。开发后更新模拟器，用户先模拟器试玩，再手机实测。
