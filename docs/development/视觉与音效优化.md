# v3.4.0 视觉与音效优化

用户要求：其余小游戏继续细化，保留各自风格、适龄引导、简化入场；不以明显的包体或流畅度代价堆素材。原仓库不改，只在新版目录开发。

## 视觉

- 木质棋盘增加木纹与浅边框；象棋/暗棋/斗兽棋棋子有柔和体积与内圈细节，黑白棋/围棋玻璃棋子增加高光；五子棋/围棋补星位，井字棋保留纸面风格。
- 水果从带汉字圆点改为西瓜剖面、橙、苹果、香蕉、葡萄、猕猴桃、草莓、樱桃和清晰炸弹，复用小SVG生成纹理。
- 地鼠使用专用渐变造型，保留探头缩回动画、洞口遮挡和打击反馈；草地与厨房背景有细节。
- 贪吃蛇棋盘由逐格绘制改为缓存纹理，蛇身增加高光和双眼；俄罗斯方块与数字方块使用共用中性纹理染色，减少重复材质。
- 音乐琴键、发光记忆按键、反应信号灯、算术面板、乒乓球场、台球桌布/袋口/球面和冰壶冰面/壶身分别细化。
- 飞行棋保留已确认的布局、规则和骰子动画，只细化机场、面板、飞机边缘与机身高光。飞机大战保留已有精细飞船和激光，限制粒子上限。
- 大厅/暂停/结算增加浅边框与浅阴影；按钮按压反馈、得分轻量粒子有上限。未增加实时模糊、全屏后处理或大型模型。
- 记忆两款保留精细动物图集，尺寸最高8×8。

所有新纹理在首次使用时生成并缓存；只上传一次，后续复用。基础开局检查生成32张小纹理，含mipmap估计4.43MiB。该数字是美术纹理缓存估算，不是整机显存/帧率测量。彩块统一一张中性纹理，蛇棋盘减少大量逐格绘制；轨迹最多36段、共享小粒子最多24个、飞机粒子最多64个。

## 音效

已将备份26个Kenney短音效接入，并补充Casino Audio的diceThrow1真实掷骰声；官方来源与CC0说明：https://kenney.nl/assets/casino-audio 、https://kenney.nl/assets/interface-sounds 、https://kenney.nl/support 。原工具与来源清单仍在 assets-library/audio/kenney-sfx-backup/tools/sfx/README.md。

钢琴/西蒙使用本项目原创加法合成C4短采样，复用播放速率产生多个音高；无需引入乐器库。来源/再生成：assets-library/audio/added-sfx/README.md、tools/sfx/prepare_godot_audio.py。

Android SoundPool预加载33个短音效（原5+备份26+掷骰1+琴音1），最多4路，同音65ms限频、结算700ms防重复，低音量射击；关音效仍保留单独震动开关。胜负旋律由GameShell门闩统一触发一次，非法操作与失败结算分开。界面、落子、走子、吃子、翻牌、配对、碰撞、砖块、蛇食物、地鼠、射击、闪灯和琴键按事件映射。
