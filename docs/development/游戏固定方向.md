# 游戏固定方向 v3.4.2-orientation

游戏方向只取 GameRegistry 的 landscape 配置。飞行棋、斗兽棋、记忆对决、切水果固定横屏，其他25款固定竖屏。大厅仍可随设备转动。

问题来源：同一个安卓 Activity 内切换游戏时没有同步 requestedOrientation；Godot 横屏使用了传感器方向；清单缺少游戏类别，Android 16 大屏会默认忽略方向限制。

修改：宿主首次进入及每次 selectGame 都设置固定方向；screen_policy.gd 共用画布配置，canvas_items / expand 保持比例并铺满可用窗口。Android 旋转异步完成，初次布局等待窗口方向匹配（最多2秒）；不重建 Activity、不重置正在进行的游戏。应用清单标记 appCategory=game。

基础检查：Godot 资源导入与手机、模拟器构建；EngineIntegrationTest#gameDirectionFollowsRegistryAcrossOppositeWindows 只检查横屏飞行棋→竖屏贪吃蛇→横屏飞行棋的窗口及画布宽高比、返回大厅。完整玩法由用户验收。

检查结果：Godot 导入无错误；ARM64 Release、x86_64 Debug 与检查 APK 构建成功；上述定向检查 OK (1 test)，模拟器已安装并打开大厅。
