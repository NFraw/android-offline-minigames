# 斗兽棋 Godot 体验版

本次仅将 animal 接入 Godot，旧 Kotlin 实现保留作参考，原仓库不改。总数仍为29款：3款 Godot（飞机大战、飞行棋、斗兽棋）+26款 Canvas。

## 玩法与图纸
以 docs/references/斗兽棋-用户规则原文.md 和用户附图为本次依据。7列9行，棋子在格内；河区为 x=1,2 / x=4,5，y=3..5（零起始），各2×3格。上方蓝方、下方红方；红先手，双方独立准备，上方文字和操作旋转180度。横屏适配手机、4:3和16:10平板。

初始上方：狮(0,0)、虎(6,0)、狗(1,1)、猫(5,1)、鼠(0,2)、豹(2,2)、狼(4,2)、象(6,2)。下方为上述位置旋转180度后的对称布阵，和参考图一致。

基础规则：四向一步、同级可吃、鼠吃象而象不吃鼠；只有鼠可入水，水陆不可跨界吃子、水鼠可互吃；狮虎沿直线跳河并按等级吃对岸棋子。按用户参考文档使用「敌鼠阻挡跳河、己鼠不阻挡」变体。不能进自己的兽穴，进敌穴、吃光对方或令对方无合法走法获胜。

陷阱仅削弱进入敌方陷阱的兽，不是无敌区域；己兽在己方陷阱仍按正常等级作战。被削弱兽战斗力为0，包括鼠和象的特殊关系。

## 休闲与比赛
默认休闲关闭计时和长追限制。
比赛模式每步30秒，准备阶段、规则页、暂停及落子动画不计时。
- 7步长追：以己方最近7次落子计数，同兽第三次进入同格且再次威胁同一敌兽时禁入。被追的兽及本序列经过陷阱者豁免。
- 17/5：最近17次己方落子均为同一只兽，含起点的活动格不超过5格时，第18次不得再进入这组格子；可以换兽或走出区域。本序列经过陷阱者豁免。
长追通过「下一步存在合法吃子走法」识别威胁；原文没有完整裁判细则，本版把此判定写明以便复核。

## 表现与生命周期
统一 Godot BoardArt 色板及奶油棋子；汉字与等级标记；水域、兽穴、陷阱与参考图对应。点选后显示合法落点和可吃目标，非法走法有文字及既有短音效反馈。
普通走子短滑移、狮虎跳河腾跃、被吃棋子缩小，动画最后一帧必定刷新并恢复输入。胜利在落子动画结束后只回调一次。尺寸变化不重置对局。无中途存盘。

## 音效备份
26个新收集音效已复制至 assets-library/audio/kenney-sfx-backup，含原 tools/sfx、已有缓存、来源说明与SHA256。WAV均为16bit/22050Hz/单声道，副本与原件校验一致。该目录不进入APK。
本次不接入这些新素材；斗兽棋仅复用原有 click/move/eat/win/lose 反馈接口。建议未来优先试听 board_place、board_slide、board_capture、ui_error、win_jingle，再按事件接入。
