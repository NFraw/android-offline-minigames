# 飞机大战：星航防线 战役设计 v3.6.1

## 一局流程

进入简短图解 → 点击开始飞行 → 6关巡航与Boss战 → 通关/机体耐久耗尽 → 结算与再来一局。保持竖屏、拖动飞机、自动开火；技能包碰到自动装备，不增加装备背包或复杂按钮。目标一局约4—6分钟，实际时间取决于命中率。

## 火力成长

三条成长线独立叠加，受击不降级，下一局重置：

| 成长线 | 升级 | 实际效果 |
| --- | --- | --- |
| 弹道 | 单发→双发→三发 | 每轮同时发射1/2/3枚，轻微展开 |
| 射速 | 初始→快射Ⅰ→快射Ⅱ | 间隔0.30/0.24/0.19秒 |
| 副武器 | 无→直射导弹→追踪导弹 | 独立发射单枚，间隔0.85/1.1秒，伤害2/1.6；仅直射导弹附0.65范围伤害，追踪弹有转向速度上限 |

主炮始终为普通子弹；双/三发和快射只强化主炮，副导弹单独冷却，不复制三枚，不随快射提速。满级追踪配置的理论直击DPS约17.24，其中追踪弹仅约1.45；需要用主炮瞄准和走位，不能靠导弹挂机清场。

第1关6秒投放双发、14秒快射Ⅰ；第2关6秒三发、15秒导弹；第3关6秒快射Ⅱ、15秒追踪导弹。补给下落，仅85单位内轻微吸附，48单位内实际拾取；12秒或越过屏幕底部后消失。超过4份丢弃最旧一份，不自动发放。每9次击落提供护盾/维修交替支援。护盾最多2层，重复满级装备不再赠送护盾，满血维修也不送护盾。

敌机基础耐久：侦察1、绕行2、装甲5、导弹机4；每两关缓慢增加。敌人数量上限12，不随分数无限加速。普通敌机漏过不扣机体耐久，减少初学者因无法覆盖整屏而受罚；必须击败每关Boss才能继续。

Boss为六种独立机体（详见下表）；在上方缓慢横移，不能直接冲撞到底部。Boss血量降到60%与25%时切换攻击节奏/扇形数，航母和终极旗舰召唤少量护卫。第一关Boss不发射导弹；后续攻击有预警、间歇和空隙。击破Boss清理危险弹、维修1点，3秒后进入下一关；终极Boss击破即胜利。

## 玩家生存与敌方弹药

初始5耐久；撞机、被子弹/导弹击中均只损失1点。护盾先挡，受击后1.6秒无敌；不会一撞直接结束，不丢武器。护盾挡伤后也有短暂保护。

敌方普通子弹红色、体积小，可躲避；敌方导弹橙色、带尾焰，耐久2，可用任意玩家弹药击落（+3分）。敌方导弹只按发射前标记的方向直飞，飞行中绝不转向追踪。击落发射者取消尚未发射的预警；Boss击败时清空危险弹，避免过关后仍被残弹命中。

上限：玩家弹72、敌机12、敌方弹28（其中导弹最多10）、预警4组、补给4、碎屑80。沿用现有矢量玩家飞机与背景；六款精细Boss使用独立透明贴图，导入限制512像素、有损压缩、按关加载。六张导入资源合计约614KiB；不引入视频、网络或新运行库。

## 引导与验收

顶部大字显示关卡、弹种、几发、快射等级和护盾；Boss有名字、阶段与血条。短提示说明刚拿到什么。三页规则分别讲拖动/补给、组合升级、预警与击落导弹。培养观察路线、选择安全空间和预判的能力。

本次数值属于首版平衡；基础验证覆盖技能叠加、导弹拦截、敌弹不追踪、受击保护与Boss进度，渲染及模拟器只做开局/暂停/返回检查。完整难度和关卡耗时由用户试玩反馈调整。

## v3.6.1 挑战性调整（2026-10-16）

第二关起Boss每轮优先预警一发瞄准玩家当前位置的普通弹，不能被拦截；发射后方向固定，可提前走位。第四关起侦察/绕行机也能发射预警普通弹；后期敌弹速度每关增加25单位/秒，重装/导弹机射击间隔逐步缩短。保留0.9秒预警、敌弹上限、5耐久与受击保护。定向回归覆盖独立副武器冷却、真实拾取、溢出/重复装备和满装备终关原地挂机失败；实际手感交由模拟器试玩。
