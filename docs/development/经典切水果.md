# 经典切水果重制

正式场景保留 `res://games/physics/fruit.tscn` 路由，模型与显示独立放在 games/fruit。大厅、安卓宿主、暂停及结算沿用现有契约。游戏数保持37款。

玩法：全屏木纹；划开菜单西瓜开始；普通水果1分；三果以上连切奖励；随机10分暴击；三次漏果结束；切炸弹立即结束；每100分补一次机会。沿滑动方向排序碰撞，炸弹之前的水果可计分，炸弹之后立即停止；不同手指不合并连切。难度随时间增加抛果数量与频率。

素材：godot/games/fruit/assets/dojo.png 与 fruits.png 使用内置 imagegen 新生成。完整提示词保存于 assets-library/artwork/fruit-classic/prompts.json。图集4×4，前7格整果、第8格炸弹、后7格对应半果、最后一格备用。没有引用原版贴图或音频。此版是经典模式的玩法与风格重制，缺少指定原版完整参考图，不能宣称像素级一致。

经典规则参考：[Halfbrick 模式说明](https://halfbrick.helpshift.com/hc/en/38-super-fruit-ninja/faq/1047-what-are-the-game-modes/)；[Halfbrick 连切与暴击说明](https://www.halfbrick.com/blog/the-ultimate-beginners-guide-to-fruit-ninja)。这些说明支持经典玩法，不代表特定2010安装包的逐帧验证。

基础检查：test_fruit_classic 覆盖切割、炸弹顺序、漏果、连切、补命与结束冻结；test_physics_view 检查正式入口、暂停与尺寸变化。只对本次改动做基础验证，随后模拟器试玩。

## v3.8.1 音效与暂停
原创离线分层合成音效：3种挥刀风切、4种破皮汁水、1种低频爆炸尾音。生成脚本 tools/prepare_fruit_audio.py；不是原版录音，未做原声一致性验证。Godot 8路限额播放，挥刀125ms限频、切果35ms限频；设置静音生效，暂停停止全部专用音效，爆炸优先清除其他声部。爆炸结束延迟1.5秒以容纳尾音。共用暂停弹窗改用暖白底、深色字、大按钮与短句，较小窗口支持滚动。
