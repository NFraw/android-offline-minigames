# 黑白棋（奥赛罗） — 策划向逻辑配置文档

## 1. 页面流转

| 阶段 | 页面/状态 | 触发条件 | 说明 |
|------|----------|---------|------|
| 入口 | 主菜单 → 游戏详情 | 点击"黑白棋"卡片 | 分类：双人对战 |
| 模式选择 | 模式选择弹窗 | 自动弹出 | 两个选项："双人对战" 或 "电脑对战" |
| 双人路线 | 双视角同意页 | 选择"双人对战" | 左右分屏，双方各自同意后开局 |
| 电脑路线 | 规则弹窗 → 直接开局 | 选择"电脑对战" | 展示规则后进入人机对战 |
| 游戏中 | 黑白棋棋盘 | 开局后 | 双方轮流落子（双人模式）或玩家执黑对战电脑（人机模式） |
| 结算 | 结算弹窗 | 双方均无子可下 | 显示黑/白方获胜或平局，含双方棋子数 |
| 重开 | 新一局棋盘 | 点击"再来一局" | 恢复初始四子布局 |

## 2. 布局结构

- **背景**：全屏深色底板（深蓝黑色）
- **标题区**：棋盘上方居中显示当前回合方和双方棋子数，格式如"● 黑方回合（2 : 2）"
- **棋盘**：8×8 绿色格子，每个格子为圆角矩形绿色底块，格间有深绿色网格线
- **棋子**：
  - 黑子：深蓝黑色实心圆
  - 白子：浅灰白色实心圆，外圈有灰色描边
- **落子提示**：当前玩家的合法落子位置显示半透明白色小圆点（仅双人模式双方可见；人机模式仅玩家回合显示）
- **棋盘定位**：水平居中，垂直方向略偏下

## 3. 按钮及交互功能

| 交互元素 | 位置 | 功能 | 反馈 |
|---------|------|------|------|
| 点击空格子（合法位置） | 棋盘内 | 落子并翻转被夹住的对方棋子 | 播放点击音效 |
| 点击空格子（非法位置） | 棋盘内 | 无效操作，忽略 | 无反馈 |
| 点击已有棋子的格子 | 棋盘内 | 无效操作，忽略 | 无反馈 |
| 暂停（基类） | 悬浮控件 | 暂停游戏 | 遮罩覆盖棋盘 |
| 重开（基类） | 悬浮控件 | 重置棋盘 | 恢复初始布局 |

## 4. 核心规则

- **棋盘**：8×8 共 64 个格子
- **玩家**：黑方和白方，黑方先手
- **初始布局**：中央 2×2 区域放置四子，对角为同色（左上白、右上黑、左下黑、右下白）
- **落子规则**：必须落在空格上，且该位置在至少一个方向上能夹住对方棋子（己方棋子在两端，中间全是对方棋子）
- **翻转规则**：落子后，所有被夹住的对方棋子立即翻转为己方颜色（八个方向逐一检测）
- **跳过规则**：当前玩家无合法落子位置时，自动跳过该回合，由对方继续
- **连续跳过**：双方均无合法落子时游戏结束
- **胜利条件**：棋盘填满或双方均无法落子时，棋子数多的一方获胜
- **平局条件**：双方棋子数相同

## 5. 特殊规则

- **落子提示**：合法落子位置显示半透明小圆点，帮助玩家判断可下位置
- **人机模式 AI 策略**：电脑采用边角加权贪心策略 —— 棋盘每个位置有预设权重值，四个角权重最高（120 分），角旁位置为负权重（-20 或 -40），AI 每回合选择合法位置中权重最高的落子
- **权重分布**：角（120）> 角邻对角线（20）> 边中（5）> 中心区（3）> 角旁直线（-20）> 角旁邻格（-40）
- **人机模式玩家固定执黑**：人机模式下玩家始终为黑方先手，电脑为白方
- **人机思考**：电脑回合短暂异步计算，界面显示"电脑思考中…"，期间玩家无法操作
- **无贴目**：本版本不实现贴目规则

## 6. 双人视角

- **双人对战模式**：
  - 进入时展示双视角同意页，左右分屏，双方各自同意后开局
  - 双方共用同一棋盘，轮流触碰屏幕落子
  - 棋盘上方显示当前回合方和双方棋子数
  - 合法落子位置均有提示小圆点，双方均可看到

- **电脑对战模式**：
  - 跳过同意页，展示规则后直接开局
  - 玩家执黑先手，点击棋盘落子
  - 电脑回合自动计算并落子，显示"电脑思考中…"
  - 仅在玩家回合显示落子提示
