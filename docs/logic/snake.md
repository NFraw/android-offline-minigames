# 贪吃蛇 — 逻辑配置文档

## 1. 页面流转

| 状态 | 触发条件 | 目标状态 | 说明 |
|------|----------|----------|------|
| 初始等待 | 进入游戏 | 初始等待 | 蛇身 3 节居中朝右，食物已随机生成，画面显示提示文字 |
| 游戏中 | 玩家首次滑动或点击方向键 | 游戏中 | 蛇开始移动，计分生效 |
| 游戏中 | 蛇头撞墙或咬到自身 | 结算 | 冻结画面，弹出结算对话框，显示死因和蛇身长度 |
| 游戏中 | 棋盘全部被蛇填满 | 结算 | 弹出胜利对话框 |
| 结算 | 点击"再来一局" | 初始等待 | 重置所有状态，分数清零，蛇身回到初始位置 |
| 结算 | 点击"返回" | 退出游戏 | 回到主菜单 |
| 游戏中 | 点击暂停按钮 | 暂停 | 画面变暗，显示暂停遮罩 |
| 暂停 | 点击继续按钮 | 游戏中 | 恢复帧循环，蛇继续移动 |

## 2. 布局结构

- **棋盘区域**：固定 16 列 × 24 行的网格，居中显示。四周有明显的灰色填充边框和亮色描边，模拟墙壁效果。
- **网格线**：半透明白色细线绘制，形成可见的格子。
- **蛇身**：圆角方块，头部颜色略亮（偏蓝），身体稍暗，头部有两个白色小圆点作为眼睛，眼睛朝向随移动方向变化。
- **食物**：红色圆形，位于某个格子中央。
- **方向键区域**：屏幕底部，十字形排列的四个方向按钮（▲▼◀▶），按钮为深色底配蓝色描边，中间有白色箭头符号。
- **提示文字**：游戏开始前，棋盘中央显示"滑动屏幕或点击下方方向键开始"。
- **顶部安全区**：棋盘从屏幕顶部 110dp 以下开始绘制，避免与 Activity 悬浮控件重叠。

| 控件 | 位置 | 交互方式 | 功能 |
|------|------|----------|------|
| ▲ 方向键 | 底部十字键上方 | 点击 | 蛇向上移动 |
| ▼ 方向键 | 底部十字键下方 | 点击 | 蛇向下移动 |
| ◀ 方向键 | 底部十字键左侧 | 点击 | 蛇向左移动 |

| 重开按钮 | Activity 悬浮层 | 点击 | 重置游戏 |

## 4. 核心规则

- **棋盘**：16 列 × 24 行的矩形网格，四周为墙壁。
- **初始状态**：蛇身 3 节，位于棋盘中央，头部朝右。
- **移动机制**：蛇以固定节奏每格移动一次。初始速度为每秒 5 格，随着得分增加逐渐加快。玩家通过滑动或方向键设定下一个移动方向。
- **方向限制**：不允许直接掉头（例如正在向右时不能直接向左），防止蛇穿过自己的身体。
- **食物生成**：食物随机出现在任意空闲格子上，每次只有一颗。
- **吃食物**：蛇头到达食物位置时，得分增加 10 分，蛇身增长一节（不移除尾部），同时在新的空闲格子上生成下一颗食物。
- **速度递增**：每累计吃掉 50 分的食物（即每吃 5 颗），速度增加 0.6 格/秒，最高速度为 13 格/秒。
- **碰撞检测**：蛇头超出棋盘边界（撞墙）或碰到蛇身任意一节（咬到自己）时，游戏立即结束。
- **胜利条件**：蛇身填满整个棋盘（所有 384 个格子），显示胜利信息。
- **失败条件**：撞墙或咬到自己，显示死因和最终蛇身长度。

## 5. 特殊规则

- **输入缓冲**：快速连续输入多个方向时，系统会按队列依次处理，不会丢弃中间的指令。但反向输入会被直接忽略。
- **待执行方向**：系统同时记录当前方向和下一个待执行方向，每一步移动时才将待执行方向设为当前方向，避免高速移动时出现方向判断错误。
- **速度计算**：实际移动频率 = 基础速度 × 时间增量。当累积的移动时间超过一格所需时间时执行一步移动，保证在不同帧率下移动速度一致。
- **格子尺寸自适应**：棋盘格子大小根据屏幕宽高自动适配，确保 16×24 的棋盘完整显示在可用区域内。
- **音效**：移动时播放移动音效，吃食物时播放吃音效，死亡时播放失败音效。

## 6. 双人视角

本游戏为单人模式，无双人视角设计。
