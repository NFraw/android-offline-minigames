# 西蒙记忆 — 逻辑配置文档

## 1. 页面流转

| 序号 | 页面/状态 | 触发条件 | 去向 |
|------|----------|---------|------|
| 1 | 主菜单 | 点击「西蒙记忆」卡片 | → 规则弹窗 |
| 2 | 规则弹窗 | 显示玩法说明，含「开始游戏」和「返回菜单」按钮 | → 游戏画面 / → 主菜单 |
| 3 | 游戏画面（展示阶段） | 游戏启动或通过当前关卡后自动进入 | → 游戏画面（输入阶段） |
| 4 | 游戏画面（输入阶段） | 颜色序列展示完毕 | → 游戏画面（展示阶段）或 → 结算弹窗 |
| 5 | 结算弹窗 | 玩家点错颜色 | → 游戏画面（重开）或 → 主菜单 |

## 2. 布局结构

- 整体深色背景（近黑色）
- 屏幕中央：2×2 方阵，四个色块围成正方形
  - 左上（红色）、右上（绿色）、左下（黄色）、右下（蓝色）
  - 每个色块为圆角矩形
  - 色块之间紧邻无间隙
- 方阵中央：圆形遮罩，叠加当前关卡文字（如「第 3 关」）
- 色块有两种状态：亮色（激活）和暗色（未激活）

## 3. 按钮及交互功能

| 控件 | 位置 | 触发方式 | 功能 |
|------|------|---------|------|
| 四个色块 | 屏幕中央 2×2 方阵 | 点击 | 输入阶段：玩家复现颜色序列；展示阶段：无响应 |
| 返回按钮 | 悬浮控件层 | 点击 | 返回主菜单 |
| 暂停按钮 | 悬浮控件层 | 点击 | 暂停/继续游戏 |

## 4. 核心规则

### 序列生成
- 初始序列长度为 1，随机从红、绿、黄、蓝四色中选一色
- 每通过一关，序列末尾追加一个随机颜色，长度加 1

### 展示阶段
- 系统按顺序逐个点亮色块，每亮一个后熄灭，再亮下一个
- 亮灯时长：0.3 秒
- 熄灭间隔：0.36 秒（连续两个相同颜色时延长至 0.55 秒，便于区分）
- 最后一个色块展示完毕后自动切换到输入阶段

### 输入阶段
- 玩家按记忆中的顺序依次点击色块
- 每次点击会触发 0.25 秒的点亮反馈动画
- 点击正确：播放音效，等待下一个输入
- 全部正确：播放通关音效，关卡数加 1，进入下一轮展示阶段

### 失败判定
- 点击的颜色与当前序列位置不匹配：游戏结束
- 播放失败音效，弹出结算弹窗，显示「记错啦！到达第 X 关」

### 得分
- 得分 = 当前关卡数 × 10

## 5. 特殊规则

- 展示阶段和暂停状态下，玩家点击色块无响应
- 游戏结束后不再响应任何点击
- 每次重置游戏时，关卡回到第 1 关，得分清零

## 6. 双人视角

本游戏为单人游戏，无双人视角规则。
