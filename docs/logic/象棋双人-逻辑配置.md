# 象棋（双人）— 策划向逻辑配置文档

## 1. 页面流转

| 阶段 | 页面/状态 | 触发条件 | 说明 |
|------|----------|---------|------|
| 入口 | 主菜单 → 游戏详情 | 点击"象棋（双人）"卡片 | 分类：双人对战 |
| 进入 | 双视角同意页 | 自动弹出 | 上下分屏，双方各自点击"点击开始"，双方都同意后才开局 |
| 游戏中 | 象棋棋盘 | 双方同意后自动进入 | 红方先手，双方轮流走子 |
| 结算 | 结算弹窗 | 将死对方 / 对方无子可走 / 一方认输 | 显示获胜方及原因，提供"再来一局"按钮 |
| 重开 | 新一局棋盘 | 点击"再来一局" | 重置棋盘、清空悔棋次数，红方先手 |

## 2. 布局结构

采用竖屏模式。

- **背景**：全屏深色底板（深蓝黑色）
- **棋盘**：10 行 × 9 列的标准中国象棋棋盘
  - 木纹渐变底板（暖色木质），圆角矩形，带双层描边
  - 楚河汉界位于第 4、5 行之间，纵向线在此处断开，中央书写"楚河""汉界"
  - 九宫格斜线：双方各有一个九宫（3~5 列 × 0~2 行为黑方，3~5 列 × 7~9 行为红方），内有对角斜线
- **棋子**：圆形渐变棋子（奶白色底），红方棋子为红字（帥仕相傌俥炮兵），黑方棋子为深色字（將士象馬車砲卒），黑方棋子字面朝上旋转 180° 便于上方玩家阅读
- **信息条**：
  - 顶部（黑方区域）：左侧悔棋按钮、中部已吃棋子列表、右侧"黑方"标签及回合指示点
  - 底部（红方区域）：左侧悔棋按钮、中部已吃棋子列表、右侧"红方"标签及回合指示点
- **状态行**：棋盘上方居中显示当前回合与将军状态（如"红方回合 · 将军！"）

## 3. 按钮及交互功能

| 交互元素 | 位置 | 功能 | 反馈 |
|---------|------|------|------|
| 点击己方棋子 | 棋盘内 | 选中该棋子，显示所有合法落点 | 播放点击音效，棋子周围出现柔光高亮，合法目标格显示圆点（空位）或红圈（吃子） |
| 点击合法目标格 | 棋盘内高亮格 | 走子或吃子 | 播放走子/吃子音效，棋子播放平滑移动动画（约 0.14 秒），吃子时播放"吃"语音并震动 |
| 再次点击已选中棋子 | 棋盘内 | 取消选中 | 高亮消失 |
| 点击己方另一棋子 | 棋盘内 | 切换选中目标 | 切换高亮 |
| 点击非法位置 | 棋盘内 | 取消选中 | 高亮消失 |
| 悔棋按钮 | 顶部/底部信息条左侧 | 发起悔棋申请（需对方同意） | 弹出确认对话框，显示剩余次数；对方点"同意"则撤销上一步，点"拒绝"则无效 |

| 暂停（基类） | 悬浮控件 | 暂停游戏 | 显示暂停遮罩 |
| 重开（基类） | 悬浮控件 | 重置棋盘 | 清空棋盘，重置悔棋次数，红方先手 |

## 4. 核心规则

### 棋盘与棋子

- 棋盘 10 行 × 9 列，中间为楚河汉界
- 每方 16 子：帅（将）1、仕（士）2、相（象）2、车（俥/車）2、马（傌/馬）2、炮（砲）2、兵（卒）5

### 各棋子走法

| 棋子 | 走法 |
|------|------|
| 帅/将 | 九宫内上下左右各一步，不可出宫 |
| 仕/士 | 九宫内斜走一步，不可出宫 |
| 相/象 | 斜走两格（田字），不可过河，若"田"字中心有子则不能走（塞象眼） |
| 马 | 走"日"字，若横向/纵向一格有子则不能走（蹩马腿） |
| 车 | 横竖直线任意距离，遇子则停（可吃敌子） |
| 炮 | 移动时同车（直线任意距离），吃子时必须隔恰好一子（炮架，任意颜色） |
| 兵/卒 | 未过河前只能前进一格；过河后可前进或左右各一步，不能后退 |

### 轮流制

- 红方先手，双方交替走子
- 每回合走一步棋

### 胜负判定

- **将死**：一方被将军且无法解除（无合法走法可解将），该方判负
- **困毙**：一方未被将军但无任何合法走法，该方判负
- **认输**：一方主动认输

### 将军检测

- 走子后检查对方帅/将是否处于被攻击状态（任何己方棋子可直接吃掉对方帅/将）
- 飞将规则：双方帅/将同列且中间无子时，视为被将军
- 被将军时状态栏显示"将军！"，帅/将位置出现脉冲红圈警示

### 走子合法性

- 不能吃己方棋子
- 走完后己方帅/将不能处于被将军状态（含飞将）
- 马有蹩腿限制，象有塞眼限制

### 走子动画

- 走子时棋子从起点平滑移动到终点，动画时长约 0.14 秒，采用缓动曲线
- 动画期间禁止操作

## 5. 特殊规则

- **悔棋机制**：每方每局最多 3 次悔棋机会。点击悔棋按钮后弹出确认对话框，需对方点击"同意"才执行撤销；动画进行中不可悔棋
- **悔棋弹窗朝向**：黑方（上方玩家）发起悔棋时，弹窗内容旋转 180° 正对黑方玩家；红方（下方玩家）发起时弹窗保持正立
- **飞将禁止**：走子后不能使己方帅/将与对方帅/将直接面对面（同列无子），即走完后不能形成飞将局面
- **最后一步标记**：走子完成后，出发格和目标格各有一个小圆点标记，提示上一步走法
- **音效与语音**：走子播放"移动"音效，吃子播放"吃"音效 + 语音"吃"，将军时语音"将军"，将死时语音"将死"，认输时语音"认输"，悔棋时语音"悔棋"

## 6. 双人视角

- **视角约定**：玩家 1（红方）面朝下（屏幕底部），玩家 2（黑方）面朝上（屏幕顶部）
- **同意页**：进入游戏时展示双视角同意页，屏幕上下分屏，下方为玩家 1（红方），上方为玩家 2（黑方），双方各自点击"点击开始"按钮，双方都同意后才正式开局
- **棋子朝向**：红方棋子文字正对下方玩家（正常方向），黑方棋子文字旋转 180° 正对上方玩家
- **信息条**：红方信息条在底部（正对红方），黑方信息条在顶部（正对黑方）
- **操作方式**：双方共用同一屏幕，轮流触摸棋盘走子。当前回合方信息条侧显示回合指示点，非回合方为灰色
- **将军提示**：被将军一方的帅/将位置出现脉冲红圈，状态栏显示"将军！"，双方均可看到
