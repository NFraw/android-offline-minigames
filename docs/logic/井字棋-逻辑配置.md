# 井字棋 — 策划向逻辑配置文档

## 1. 页面流转

| 阶段 | 页面/状态 | 触发条件 | 说明 |
|------|----------|---------|------|
| 入口 | 主菜单 → 游戏详情 | 点击"井字棋"卡片 | 分类：双人对战 |
| 进入 | 双视角同意页 | 自动弹出 | 左右分屏，双方各自点击"点击开始"，双方都同意后才开局 |
| 游戏中 | 井字棋棋盘 | 双方同意后自动进入 | 双人轮流落子 |
| 结算 | 结算弹窗 | 一方三子连线或棋盘满 | 显示获胜方或平局，提供"再来一局"按钮 |
| 重开 | 新一局棋盘 | 点击"再来一局" | 自动交换先手方，重新开始 |

## 2. 布局结构

- **背景**：全屏深色底板（深蓝黑色）
- **标题区**：棋盘上方居中显示当前轮到哪方落子，文字为灰色
- **棋盘**：3×3 格子，每个格子为圆角矩形深色底块，格间有浅蓝灰色网格线分隔
- **棋子**：
  - X 方（玩家 1）：橙红色叉号（两条交叉斜线，线条圆头）
  - O 方（玩家 2）：蓝紫色圆圈
- **棋盘定位**：水平居中，垂直方向略偏下（上方留出标题空间）

## 3. 按钮及交互功能

| 交互元素 | 位置 | 功能 | 反馈 |
|---------|------|------|------|
| 点击空格子 | 棋盘内任意空格 | 当前玩家落子 | 播放点击音效，显示棋子 |
| 点击已有棋子的格子 | 棋盘内 | 无效操作，忽略 | 无反馈 |
| 点击棋盘外区域 | 棋盘外 | 无效操作，忽略 | 无反馈 |
| 暂停（基类） | 悬浮控件 | 暂停游戏，显示暂停遮罩 | 遮罩覆盖棋盘 |
| 重开（基类） | 悬浮控件 | 重置棋盘，交换先手 | 清空棋盘，重新开始 |

## 4. 核心规则

- **棋盘**：3×3 共 9 个格子
- **玩家**：双方对弈，X 方（玩家 1）和 O 方（玩家 2）
- **轮流制**：双方交替落子，每回合只能在一个空格放一枚棋子
- **先手规则**：首局 X 方先手；每次重开后自动交换先手（上局的后手方变为下局的先手方）
- **胜利条件**：横、竖、斜任意方向连续三子为同一方，该方获胜
- **平局条件**：9 个格子全部填满且无人三子连线，判定为平局
- **计分**：本游戏无累计得分，仅判定单局胜负

## 5. 特殊规则

- **先手轮换**：每局结束重开时，先手方自动交换。即上局 X 先手则下局 O 先手，反之亦然
- **无悔棋**：落子后不可撤回
- **无超时**：不限制思考时间
- **无禁手**：任意空格均可落子，无额外限制

## 6. 双人视角

- **视角约定**：玩家 1 面朝下（屏幕底部），玩家 2 面朝上（屏幕顶部）
- **同意页**：进入游戏时展示双视角同意页，屏幕左右分屏，左侧为玩家 1，右侧为玩家 2，双方各自点击"点击开始"按钮，双方都同意后才正式开局
- **操作方式**：双方共用同一屏幕，轮流触碰棋盘格子落子，无需翻转视角（棋盘为对称的 3×3 格，双方看到的画面一致）
- **轮次提示**：棋盘上方显示当前轮到哪方（"✕ 玩家1 落子" 或 "○ 玩家2 落子"），双方均可看到
- **结算提示**：获胜时弹出"X 方三子连线获胜！"或"O 方三子连线获胜！"，平局时弹出"平局！"
