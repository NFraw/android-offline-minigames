# 台球（8 球） — 逻辑配置文档

## 2. 布局结构

全屏竖屏或横屏自适应，球桌长边跟随屏幕方向。

- **顶部信息栏**：当前玩家标识条（红/蓝底色）+ 状态文字（瞄准/运动/放置/叫袋），下方显示实球剩余数、8 号球状态、花球剩余数。桌面开放时额外显示提示。
- **球桌区域**：居中显示，绿色台面 + 棕色木框 + 6 个袋口（四角 + 长边中点各一）。竖屏时台面竖放，横屏时横放。
- **发球区**：竖屏为台面底部 22% 区域，横屏为左侧 22% 区域，以虚线标示。
- **脚点**：远离发球区一侧，三角架开球位置。
- **控制区**：右下角"辅助线"开关按钮，底部提示文字。

## 3. 按钮及交互功能

| 控件 | 位置 | 功能 |
|-----|------|------|
| 辅助线开关 | 右下角 | 切换虚线辅助线的显示/隐藏 |
| 台面（放置态） | 点击台面任意位置 | 放置母球（犯规球在手中时） |
| 袋口高亮（叫袋态） | 6 个袋口位置 | 点击选择 8 号球目标袋口 |

**瞄准操作**：按住台面任意位置并反向拖动（拖动方向与击球方向相反），画面显示球杆跟随。松手后击球。拖动距离决定击球力度（15%-100%）。

## 4. 核心规则

**球的分类**：
- 1-7 号：实球（纯色）
- 8 号：黑球（决胜球）
- 9-15 号：花球（白底色带）
- 0 号：母球（白色）

**开球**：
- 母球置于发球区，目标球三角架置于脚点。8 号球居中，后两角分别为一实一花，其余随机排列。
- 开球后桌面开放，首次合法进球方确定球组（实球或花球）。
- 开球进球可续击，桌面保持开放。
- 开球犯规（母球落袋或未碰任何球）：对方获得球在手中，限定在发球区放置。

**球组分配**：
- 桌面开放期间（group1 = 0），首次有己方球合法入袋时确定球组。
- 确定后，当前玩家为实球组则对方为花球组，反之亦然。

**击球判定**：
- 母球首先碰到的球必须属于当前玩家的球组，否则犯规。
- 若已清光己方球组，则必须首先碰到 8 号球。
- 母球落袋 = 犯规。
- 母球未碰到任何球 = 犯规。

**犯规处理**：
- 犯规方本杆结束，对方获得"球在手中"。
- 一般犯规：可在台面任意位置放置母球。
- 开球犯规：限定在发球区放置。
- 放置时自动寻找不与其他球重叠的最近位置。

**胜负判定**：
- 己方球组全部清光后，打 8 号球前必须先选袋口（叫袋）。
- 合法打进 8 号球（无犯规 + 己方球组已清光 + 进了所叫袋口）= 获胜。
- 犯规时进 8 号球 = 判负。
- 己方球组未清光就进 8 号球 = 判负。
- 8 号球未进所叫袋口 = 判负。
- 开球时 8 号进袋不算负，摆回脚点继续。

**续击条件**：本杆有己方球组的球入袋且无犯规，可继续击球；否则换对方。

**物理参数**：
- 库边回弹系数：0.82
- 台面摩擦阻尼：指数衰减，系数 1.6
- 静止判定速度阈值：3（低于此速度的球视为停止）

## 5. 特殊规则

- **辅助线**：可开关的虚线辅助线，从母球中心沿击球方向延伸，标记首个碰到的目标球位置（黄色高亮圈）。
- **开球 8 号特殊处理**：开球阶段打进 8 号球不算胜负，将 8 号球摆回脚点附近随机位置继续。
- **球组剩余显示**：顶部信息栏实时显示实球和花球各自剩余数量，以及 8 号球是否在场。
- **桌面开放提示**：球组未定时，界面显示黄色提示"桌面开放 · 首杆合法进球定球组"。
- **放置母球防重叠**：放置母球时自动搜索不与其他球重叠的最近落点，搜索范围逐步扩大。
- **8 号球摆回**：开球进 8 号后摆回脚点，若脚点被占则在台面中央 30%-70% 区域随机寻找空位。

## 6. 双人视角

本游戏为双人轮流同屏设计，不区分上下视角：

- **玩家 1**：使用红色标识，开球先手。
- **玩家 2**：使用蓝色标识。
- **当前玩家提示**：顶部信息栏以当前玩家对应颜色显示"玩家 X（球组名）· 状态"。
- **球组分配**：桌面开放时双方球组未定，首次合法进球后根据进球方确定。进球方为实球则对方为花球，反之亦然。
- **球在手中**：犯规后对方获得球在手中权利，需点击台面放置母球。放置完成后自动进入瞄准态。
