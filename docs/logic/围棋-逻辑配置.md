# 围棋（15×15 简易版） — 策划向逻辑配置文档

## 1. 页面流转

| 阶段 | 页面/状态 | 触发条件 | 说明 |
|------|----------|---------|------|
| 入口 | 主菜单 → 游戏详情 | 点击"围棋"卡片 | 分类：双人对战 |
| 进入 | 双视角同意页 | 自动弹出 | 左右分屏，双方各自同意后开局 |
| 游戏中 | 围棋棋盘 | 双方同意后自动进入 | 黑白轮流落子或虚手 |
| 结算 | 结算弹窗 | 双方连续虚手两次 | 显示胜负结果及详细分数，提供"再来一局"按钮 |
| 重开 | 新一局棋盘 | 点击"再来一局" | 清空棋盘，黑方先手，重新开始 |

## 2. 布局结构

- **背景**：全屏深色底板（深蓝黑色）
- **棋盘底板**：木色（暖黄色）圆角矩形，模拟真实棋盘
- **棋盘网格**：15×15 线条网格（棕色），交叉点为落子位置
- **星位标记**：棋盘上 9 个星位（天元及四角四边星位）以棕色小圆点标注，坐标为 (3,3)、(3,7)、(3,11)、(7,3)、(7,7)、(7,11)、(11,3)、(11,7)、(11,11)
- **棋子**：
  - 黑子：深色实心圆，带灰色高光底层
  - 白子：浅灰白色实心圆，外圈有灰色描边
- **最后一手标记**：最后一颗落子位置显示红色小圆点
- **回合指示区**：棋盘上方显示当前落子方（以真实棋子图形 + 文字"黑方落子"或"白方落子"），左侧画一枚棋子图形
- **提子计数**：回合指示下方显示"提子：黑提 X · 白提 Y"
- **虚手按钮**：棋盘下方居中，圆角矩形深色按钮，文字为"黑方虚手"或"白方虚手"（随当前落子方变化）
- **提示栏**：底部居中显示"点击落子 · 虚手跳过 · 双方连续虚手两次后终局"
- **棋盘定位**：水平居中，垂直方向略偏下（上方留出回合指示空间，下方留出虚手按钮空间）

## 3. 按钮及交互功能

| 交互元素 | 位置 | 功能 | 反馈 |
|---------|------|------|------|
| 点击棋盘交叉点 | 棋盘内靠近交叉点 | 在该位置落子 | 播放点击音效，显示棋子，切换回合 |
| 点击棋盘空旷处（远离交叉点） | 棋盘内但不在交叉点附近 | 无效操作，忽略 | 无反馈 |
| 点击已有棋子的交叉点 | 棋盘内 | 无效操作，忽略 | 播放失败音效 |
| 点击自杀位置 | 棋盘内 | 自杀禁着，拒绝落子 | 播放失败音效 |
| 点击虚手按钮 | 棋盘下方按钮区 | 跳过本回合 | 播放移动音效，切换回合 |
| 双方连续虚手 | 两次虚手 | 终局，进入计分 | 自动触发结算 |
| 暂停（基类） | 悬浮控件 | 暂停游戏 | 遮罩覆盖棋盘 |
| 重开（基类） | 悬浮控件 | 重置棋盘 | 清空棋盘，重新开始 |

## 4. 核心规则

- **棋盘**：15×15 共 225 个交叉点
- **玩家**：黑方和白方，黑方先手
- **轮流制**：双方交替落子或虚手
- **落子规则**：点击靠近交叉点的位置（距离交叉点不超过格子宽度的 45%），在该交叉点放置一枚己方棋子
- **提子规则**：落子后，检查对方棋子的每个相邻连通 group，若该 group 无气（所有相邻点均被占据），则将该 group 整体提掉（从棋盘移除）
- **自杀禁着**：落子后若己方刚落的棋子所在的连通 group 无气，且未提掉任何对方棋子，则该落子被拒绝（不允许自杀）
- **虚手**：点击"虚手"按钮跳过本回合，不落子
- **终局条件**：双方连续各虚手一次（即连续两次虚手），游戏结束
- **计分规则（数子法）**：
  - 棋子数：棋盘上黑子和白子各有多少
  - 围空：通过泛洪填充计算所有空区域，若一片空区域仅与黑子相邻则为黑方围空，仅与白子相邻则为白方围空，同时与黑白相邻则为公气不计入任何一方
  - 总分 = 棋子数 + 围空
  - 总分高的一方获胜，相同则平局
- **提子计数**：界面实时显示黑方提掉白方多少子、白方提掉黑方多少子

## 5. 特殊规则

- **无打劫规则**：本简易版不实现打劫禁止（即允许循环提子），实际使用中极为罕见
- **无贴目**：本版本不实现贴目（正式围棋黑方先行需贴 7.5 目），简化处理
- **无点目**：采用数子法而非数目法，直接以棋子数 + 围空判定
- **落子吸附**：点击位置会自动吸附到最近的交叉点（距离不超过格子宽度 45% 才生效），方便触屏操作
- **连通 group 检测**：提子判定基于连通 group（同色棋子通过上下左右相邻关系连通），而非单颗棋子
- **气的定义**：一个连通 group 的气 = 该 group 中所有棋子的相邻空交叉点的并集，只要有一个相邻空点即有气
- **终局详细报告**：结算时显示双方棋子数、围空数和总分，格式如"黑方获胜！黑 85 : 72 白（黑子 40 + 围空 45，白子 35 + 围空 37）"

## 6. 双人视角

- **视角约定**：玩家 1 面朝下（屏幕底部），玩家 2 面朝上（屏幕顶部）
- **同意页**：进入游戏时展示双视角同意页，屏幕左右分屏，左侧为玩家 1，右侧为玩家 2，双方各自点击"点击开始"，双方都同意后正式开局
- **操作方式**：双方共用同一屏幕，轮流触碰棋盘交叉点落子或点击虚手按钮
- **棋盘对称**：15×15 棋盘为完全对称结构，双方看到的画面一致，无需翻转视角
- **回合提示**：棋盘上方以真实棋子图形和文字提示当前落子方，双方均可看到
- **虚手按钮**：按钮文字随当前落子方动态变化（"黑方虚手"/"白方虚手"），明确提示当前是哪方操作
