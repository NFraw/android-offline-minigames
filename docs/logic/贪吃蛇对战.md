# 贪吃蛇对战 — 逻辑配置文档

## 1. 页面流转

| 序号 | 页面/状态 | 触发条件 | 去向 |
|------|----------|---------|------|
| 1 | 主菜单 | 点击「贪吃蛇对战」卡片 | → 双人规则同意页 |
| 2 | 双人规则同意页 | 分屏显示，双方各自点击「点击开始」 | → 游戏画面 |
| 3 | 游戏画面 | 双方同意后进入 | → 结算弹窗 |
| 4 | 结算弹窗 | 两条蛇都死亡 | → 游戏画面（重开）或 → 主菜单 |

## 2. 布局结构

- 深色背景
- 屏幕上半区：玩家 1 方向键（十字排列：上、左、右、下）+ 操作提示
- 屏幕中央：游戏棋盘区域
  - 四周有明显的墙壁边框（填充 + 亮色描边），撞墙即死
  - 内部有淡色网格线
  - 屏幕中线有分隔线，区分上下半区
- 屏幕下半区：玩家 2 方向键（十字排列：上、左、右、下）+ 操作提示
- 棋盘上显示：两条蛇身（玩家 1 绿色，玩家 2 橙色）、食物（红色圆形）

## 3. 按钮及交互功能

| 控件 | 位置 | 触发方式 | 功能 |
|------|------|---------|------|
| 玩家 1 方向键（▲◀▶▼） | 屏幕上方区域 | 点击 | 控制玩家 1 蛇的移动方向 |
| 玩家 2 方向键（▲◀▶▼） | 屏幕下方区域 | 点击 | 控制玩家 2 蛇的移动方向 |
| 上半屏滑动区 | 棋盘上半部分 | 手指滑动 | 控制玩家 1 蛇的移动方向（备选操控） |
| 下半屏滑动区 | 棋盘下半部分 | 手指滑动 | 控制玩家 2 蛇的移动方向（备选操控） |
| 返回按钮 | 悬浮控件层 | 点击 | 返回主菜单 |
| 暂停按钮 | 悬浮控件层 | 点击 | 暂停/继续游戏 |

## 4. 核心规则

### 蛇的初始状态
- 玩家 1（绿色）：初始 3 节，位于棋盘左侧中央，向右移动
- 玩家 2（橙色）：初始 3 节，位于棋盘右侧中央，向左移动
- 开局时两条蛇静止不动，直到对应玩家首次操作方向键或滑动

### 移动规则
- 游戏以固定节奏逐步推进（每拍移动一格）
- 移动速度：每秒 5.5 拍
- 方向缓冲机制：新输入的方向在下一拍才生效，防止快速连按导致 180° 掉头撞自己
- 不可直接反向（与当前方向或待执行方向相反的输入均被忽略）

### 食物规则
- 初始棋盘上有 3 个食物（红色圆形）
- 蛇头吃到食物后：蛇身尾部不缩回（即身体加长 1 节），同时在随机空位生成新食物
- 食物不会生成在蛇身或已有食物的位置上

### 碰撞判定（每拍依次检查）
1. **撞墙**：蛇头移出棋盘边界 → 该蛇立即死亡
2. **头撞头**：两条蛇头同时到达同一格 → 两条蛇同时死亡
3. **撞对方身体**：蛇头撞到对方蛇身任意一节 → 该蛇死亡（仅检查双方都还活着的情况）
4. **撞自己身体**：蛇头撞到自己身体任意一节 → 该蛇死亡

### 结算规则
- 一条蛇死亡后，另一条蛇继续独自游戏
- 两条蛇都死亡后，比较双方蛇身长度（节数）
- 蛇身更长的一方获胜；长度相同则平局
- 结算弹窗显示双方最终节数

### 棋盘尺寸
- 列数：根据屏幕宽度计算，最多 16 列
- 行数：根据屏幕剩余高度（扣除上下方向键区域）计算

## 5. 特殊规则

- 一条蛇死亡后，其蛇身仍留在棋盘上，但不再阻挡幸存者的移动（幸存者可以穿过死亡蛇的身体）
- 暂停状态下蛇不会移动，方向键和滑动操作仍可输入
- 开局时蛇静止不动，等待玩家首次操作后才开始移动

## 6. 双人视角

- 通过双人同意页进入：屏幕分上下两半，各显示一位玩家的规则说明，双方都点击「点击开始」后才开局
- 玩家 1 使用上半屏的方向键或滑动控制绿色蛇
- 玩家 2 使用下半屏的方向键或滑动控制橙色蛇
- 屏幕中线有分隔线，明确区分两位玩家的操作区域
- 两位玩家共享同一棋盘视角，面对面操作
