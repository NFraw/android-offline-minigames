# 五子棋 — 逻辑配置文档

## 1. 页面流转

| 序号 | 页面/状态 | 触发条件 | 去向 |
|------|----------|---------|------|
| 1 | 主菜单 | 点击「五子棋」卡片 | → 模式选择弹窗 |
| 2 | 模式选择弹窗 | 显示「双人对战」和「电脑对战」两个按钮，以及「返回菜单」 | → 双人规则同意页 / → 人机规则弹窗 / → 主菜单 |
| 3 | 双人规则同意页 | 选择「双人对战」后进入，分屏显示，双方各自点击「点击开始」 | → 双人对战游戏画面 |
| 4 | 人机规则弹窗 | 选择「电脑对战」后进入，显示规则说明 | → 人机对战游戏画面 |
| 5 | 双人对战游戏画面 | 双方同意后进入 | → 结算弹窗 |
| 6 | 人机对战游戏画面 | 点击「开始游戏」后进入 | → 结算弹窗 |
| 7 | 结算弹窗 | 一方五连或棋盘满 | → 游戏画面（重开）或 → 主菜单 |

## 2. 布局结构

### 共通布局
- 深色背景
- 屏幕中央：15×15 棋盘，木色背景，深棕色网格线
- 棋盘上方：当前回合提示文字（如「● 黑方落子」或「○ 白方落子」）
- 棋盘四角及中央有星位标记点（共 5 个）

### 双人对战模式
- 棋盘上方提示当前落子方
- 黑方先手，双方轮流在同一屏幕上落子

### 人机对战模式
- 棋盘上方提示「你（黑）落子」或「🤖 电脑思考中…」
- 棋盘下方提示「黑方先手，先连成五子者胜」
- 玩家执黑先手，电脑执白后手

## 3. 按钮及交互功能

| 控件 | 位置 | 触发方式 | 功能 |
|------|------|---------|------|
| 棋盘交叉点 | 屏幕中央 15×15 网格 | 点击交叉点附近 | 落子（需在交叉点 0.45 格距内） |
| 「双人对战」按钮 | 模式选择弹窗 | 点击 | 进入双人规则同意页 |
| 「电脑对战」按钮 | 模式选择弹窗 | 点击 | 进入人机规则弹窗 |
| 「开始游戏」按钮 | 规则弹窗 | 点击 | 进入游戏 |
| 「返回菜单」按钮 | 弹窗中 | 点击 | 返回主菜单 |
| 返回按钮 | 悬浮控件层 | 点击 | 返回主菜单 |
| 暂停按钮 | 悬浮控件层 | 点击 | 暂停/继续游戏 |

## 4. 核心规则

### 棋盘与棋子
- 标准 15×15 棋盘
- 黑方先行，双方轮流落子
- 每次只能在空位落子，不可悔棋

### 胜负判定
- 横、竖、左斜、右斜四个方向，任意方向先连成五子（或以上）的一方获胜
- 落子后立即检查是否五连
- 棋盘全部下满仍无五连：平局

### 最后一手标记
- 最后落子的位置会显示红色圆点标记，便于双方确认上一步

### 人机模式 AI 策略
- AI 在独立线程中计算，避免阻塞界面
- 对每个空位进行攻防评估打分：
  - 进攻分（AI 自己形成连线的潜力）权重 ×2
  - 防守分（阻挡玩家连线的紧迫性）权重 ×1
- 评分等级：五连（100000）> 活四（10000）> 冲四（5000）> 活三（1000）> 眠三（300）> 活二（100）> 眠二（30）
- 取攻防总分最高的位置落子

## 5. 特殊规则

- 点击位置距离最近交叉点超过 0.45 格距时，视为无效点击，不落子
- 点击已有棋子的位置无效
- 人机模式下，AI 思考期间玩家无法落子
- 暂停状态下无法落子

## 6. 双人视角

### 双人对战模式
- 通过双人同意页进入：屏幕分上下两半，各显示一位玩家的规则说明，双方都点击「点击开始」后才开局
- 两位玩家共享同一屏幕视角，面向棋盘的同一方向
- 黑方先手，白方后手，通过屏幕上方文字提示当前轮到哪方

### 人机对战模式
- 玩家始终执黑（先手），电脑执白
- 无双人视角切换，为单人对 AI 的游戏
