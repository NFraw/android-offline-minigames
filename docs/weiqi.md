# 围棋（Weiqi）游戏逻辑文档

## 1. 游戏类型与视角

- **类型**：双人回合制
- **视角约定**：共享 15×15 棋盘，黑方先手，轮流落子。支持"虚手"（跳过回合），双方连续虚手两次后终局。
- **屏幕方向**：竖屏

## 2. 数据模型

```kotlin
private const val N = 15          // 棋盘尺寸（15×15）
private const val EMPTY = 0      // 空位
private const val BLACK = 1      // 黑方
private const val WHITE = 2      // 白方

private val board = IntArray(N * N)   // 棋盘状态（一维数组，row-major）
private var curPlayer = BLACK         // 当前落子方
private var passCount = 0             // 连续虚手计数
private var lastMove = -1             // 最后一手位置（用于标记显示）
private var over = false
private var capturedW = 0             // 黑方提白子数
private var capturedB = 0             // 白方提黑子数

// 布局参数
private var cell = 0f            // 格子像素大小
private var boardLeft = 0f       // 棋盘左边界
private var boardTop = 0f        // 棋盘上边界
private var stoneR = 0f          // 棋子半径
private val passBtn = RectF()    // 虚手按钮区域
```

## 3. 初始化逻辑（reset）

1. 清空棋盘：所有格子设为 `EMPTY`
2. `curPlayer = BLACK`（黑方先手）
3. `passCount = 0`，`lastMove = -1`
4. `over = false`
5. `capturedW = capturedB = 0`
6. 调用 `start()`

## 4. 输入处理

- 仅处理 `ACTION_DOWN`，且 `over` 或 `paused` 时忽略

### 4.1 虚手按钮
- 触摸点在 `passBtn` 区域内：
  - `passCount++`
  - 播放 MOVE 音效
  - 如果 `passCount >= 2` → 调用 `finish()` 终局
  - 否则切换到对方回合

### 4.2 落子
- 将触摸坐标转换为最近的棋盘交叉点 `(c, r)`
- 距离检查：触摸点到交叉点距离必须 `<= cell * 0.45`
- 调用 `place(c, r)` 尝试落子
  - 成功 → 切换到对方回合
  - 失败（自杀禁着）→ 播放 LOSE 音效

## 5. 核心更新循环（update(dt)）

无逻辑 —— 本游戏为回合制。

## 6. 核心算法

### 6.1 place(x, y) —— 落子与提子

1. 目标位置必须为空
2. 在目标位置放置当前玩家棋子
3. **提子检查**：检查相邻 4 个方向，如果相邻位置是对方棋子：
   - 用 `groupAt()` 找到该棋子所在的连通块
   - 用 `groupHasLiberty()` 检查该连通块是否有气
   - 无气 → 提掉整个连通块（设为 EMPTY），累加提子数
4. **自杀检查**：如果本轮没有提子，检查己方棋子所在连通块是否有气
   - 无气 → 自杀禁着，撤销落子，返回 false
5. 更新 `lastMove`，重置 `passCount`

### 6.2 groupAt(idx, player) —— 连通块搜索

- 使用 BFS/DFS 从 `idx` 出发，收集所有相邻的同色棋子
- 返回连通块的所有位置索引列表

### 6.3 groupHasLiberty(group) —— 气的检查

- 遍历连通块中每个棋子的相邻 4 个方向
- 如果任意相邻位置为空 → 有气，返回 true

### 6.4 neighbors(i) —— 相邻位置

- 返回上下左右 4 个方向的相邻位置索引（处理边界）

### 6.5 finish() —— 终局计分

采用**数子法**（子数 + 围空）：

1. 统计棋盘上黑子数 `blackStones` 和白子数 `whiteStones`
2. **围空计算**：用 flood fill 遍历所有空区域
   - 对每个未访问的空位，BFS 收集整个空连通块
   - 检查该空连通块相邻的棋子颜色
   - 仅接触黑子（不接触白子）→ 黑方围空
   - 仅接触白子（不接触黑子）→ 白方围空
   - 同时接触双方 → 中立区域，不计入
3. **总分**：`bTotal = blackStones + blackTerr`，`wTotal = whiteStones + whiteTerr`
4. 比较总分判定胜负

## 7. 胜负判定

- **终局条件**：双方连续虚手（`passCount >= 2`）
- **计分方式**：数子法（棋子数 + 围空）
- **胜负规则**：总分高者获胜
- **结算**：
  - 黑多 → "黑方获胜！"
  - 白多 → "白方获胜！"
  - 相等 → "平局！"
- **结算信息**：包含详细分子数和围空数

## 8. 边界与特殊规则

- ✅ **打劫（禁全同）**：落子后的局面不能与「上一手之前的局面」完全相同，因此不能立即回提；**虚手可解消劫争**（虚手后清空该限制）。
- ⚠️ **不实现贴目**：当前版本没有贴目规则，黑方有先手优势。
- ⚠️ **自杀禁着**：落子后如果己方连通块无气且未提对方棋子，该落子非法。
- ⚠️ **虚手机制**：虚手不落子，直接跳过回合。连续两次虚手（双方各一次或同一方连续两次）即终局。
- ⚠️ **触摸精度**：使用 `Math.round()` 对齐到最近交叉点，距离超过 `cell * 0.45` 则忽略。
- ⚠️ **围空中立**：空区域同时接触黑白双方棋子时，该区域不计入任何一方围空。
- ⚠️ **星位标记**：在 (3,3), (3,7), (3,11), (7,3), (7,7), (7,11), (11,3), (11,7), (11,11) 绘制星位点。

## 9. 渲染要求

- **棋盘底板**：木纹色（`0xFFE0B577`），圆角矩形
- **网格线**：棕色（`0xFF8A5A2B`），15×15 线条
- **星位**：9 个星位点（3,7,11 行列组合）
- **黑子**：深色渐变（外层 `0xFF4A5568`，内层 `0xFF1C2333`）
- **白子**：白色（`0xFFF5F6FA`），带浅灰描边（`0xFFB9C0CE`）
- **最后一手标记**：红色小圆点（`0xFFE8503A`）
- **回合指示**：左侧绘制真实棋子图形 + "黑方/白方落子"文字
- **提子统计**：显示"提子：黑提 X · 白提 X"
- **虚手按钮**：底部居中，显示"黑方/白方虚手"
- **提示文字**："点击落子 · 虚手跳过 · 双方连续虚手两次后终局"
